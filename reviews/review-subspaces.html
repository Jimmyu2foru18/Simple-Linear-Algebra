Vector Spaces & Subspaces

Comprehensive review of vector spaces, subspaces, span, linear independence, basis, dimension, and the four fundamental subspaces. Covers chapters 5–10 from Gilbert Strang's MIT 18.06 course.

1. Vector Spaces

A vector space $V$ over a field $\mathbb{R}$ is a set of elements called vectors, together with two operations: vector addition and scalar multiplication, satisfying eight axioms (closure, associativity, commutativity, identity, inverse, distributivity).

1.1 Key Axioms

  • Closure under addition: If $\mathbf{u}, \mathbf{v} \in V$, then $\mathbf{u} + \mathbf{v} \in V$
  • Closure under scalar multiplication: If $c \in \mathbb{R}$ and $\mathbf{v} \in V$, then $c\mathbf{v} \in V$
  • Zero vector: There exists $\mathbf{0} \in V$ such that $\mathbf{v} + \mathbf{0} = \mathbf{v}$
  • Additive inverse: For each $\mathbf{v} \in V$, there exists $-\mathbf{v} \in V$

2. Subspaces

A subspace $W$ of a vector space $V$ is a subset that is itself a vector space under the same operations. The key test is the Subspace Test.

2.1 Subspace Test

A nonempty subset $W \subseteq V$ is a subspace if and only if:
  1. $\mathbf{u} + \mathbf{v} \in W$ for all $\mathbf{u}, \mathbf{v} \in W$ (closed under addition)
  2. $c\mathbf{u} \in W$ for all $c \in \mathbb{R}, \mathbf{u} \in W$ (closed under scalar multiplication)

2.2 Span

$$\text{span}\{\mathbf{v}_1, \ldots, \mathbf{v}_k\} = \{c_1\mathbf{v}_1 + \cdots + c_k\mathbf{v}_k : c_i \in \mathbb{R}\}$$
Span definition

The span of a set of vectors is the set of all possible linear combinations. It is always a subspace.

2.3 Column Space and Nullspace

  • Column Space $C(A)$: Span of the columns of $A$; subspace of $\mathbb{R}^m$
  • Nullspace $N(A)$: Set of all $\mathbf{x}$ such that $A\mathbf{x} = \mathbf{0}$; subspace of $\mathbb{R}^n$

3. Linear Independence

A set of vectors $\{\mathbf{v}_1, \ldots, \mathbf{v}_k\}$ is linearly independent if the only solution to $c_1\mathbf{v}_1 + \cdots + c_k\mathbf{v}_k = \mathbf{0}$ is $c_1 = \cdots = c_k = 0$.

3.1 Key Tests

  • Vectors are independent if no vector in the set can be written as a linear combination of the others
  • If $\text{rank}(A) = n$ (number of columns), columns are independent
  • More than $n$ vectors in $\mathbb{R}^n$ are always dependent

3.2 Wronskian Test (Functions)

For functions $f_1, \ldots, f_n$, construct the Wronskian matrix. If $\det(W) \neq 0$ on an interval, the functions are linearly independent.

4. Basis & Dimension

A basis for a vector space $V$ is a linearly independent set that spans $V$. The dimension is the number of vectors in any basis.

4.1 Key Properties

  • Every vector in $V$ can be written uniquely as a linear combination of basis vectors
  • All bases for $V$ have the same number of vectors
  • If $V$ has dimension $n$, any set of $n$ independent vectors is a basis
  • Any spanning set with $n$ vectors is a basis

4.2 Dimension Theorem

$$\text{dim}(C(A)) + \text{dim}(N(A)) = n$$
Rank-nullity theorem for $A_{m \times n}$

5. The Four Fundamental Subspaces

For any $m \times n$ matrix $A$, there are four fundamental subspaces that completely characterize the matrix.
