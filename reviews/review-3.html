Homogeneous Systems & Independence

Comprehensive review of reduced row echelon form, pivot & free variables, special solutions, row reduced form, and independence, basis & dimension. Covers chapters 7–9 from Gilbert Strang's MIT 18.06 course.

1. Reduced Row Echelon Form (RREF)

The RREF of a matrix is the simplest equivalent matrix obtained by complete elimination. In RREF, every pivot is 1, each pivot is the only nonzero entry in its column, and pivots appear to the right as we move down rows.

1.1 RREF Conditions

A matrix is in reduced row echelon form if it satisfies:

  1. All nonzero rows are above any rows of all zeros
  2. Each leading entry (pivot) is 1
  3. Each leading 1 is the only nonzero entry in its column
  4. Each leading 1 is to the right of the leading 1 in the row above

1.2 RREF and the Identity Matrix

If $A$ is invertible, $\text{RREF}(A) = I$. If $A$ is singular, $\text{RREF}(A)$ has at least one zero row. The RREF reveals the rank, pivot positions, and structure of the solution space.

1.3 Key Properties

RREF is Unique: Every matrix has exactly one RREF. No matter which sequence of row operations you use, you will always arrive at the same final reduced form.

1.4 From RREF to Special Solutions

2. Pivot & Free Variables

Pivot variables correspond to pivot columns and are determined by the system. Free variables correspond to non-pivot columns and can be assigned arbitrary values. The number of free variables equals the dimension of the nullspace.

2.1 Pivot Variables

Pivot variables are the unknowns corresponding to pivot columns in the RREF. They are determined by the system and take whatever values are forced upon them by the equations.

2.2 Free Variables

Free variables are the unknowns corresponding to non-pivot columns. They can be assigned any value, and each free variable introduces a parameter into the solution set.

2.3 Counting Variables

$$\text{Number of free variables} = n - r$$
Free variables = total variables $-$ rank

For an $m \times n$ matrix $A$ with rank $r$:

  • $r$ pivot variables (determined)
  • $n - r$ free variables (arbitrary)

2.4 Key Insight

Mnemonic: "Free to Choose, Pivot to Obey"
Free variables you can assign any value. Pivot variables must obey the equations and take whatever values are forced upon them.

3. Special Solutions

To find a basis for the nullspace, set each free variable to 1 (one at a time, others to 0) and solve for the pivot variables. Each choice produces one special solution. All special solutions span the nullspace.

3.1 Finding Special Solutions from RREF

Given RREF $R$ with $r$ pivots and $n-r$ free variables:

  1. Set one free variable to 1, all others to 0
  2. Read pivot values from $R$
  3. One special solution: $x$ has 1 in position $j$, $-R_{ij}$ in each pivot row $i$'s column $j$
  4. Repeat for each free variable to get the basis of $N(A)$

3.2 Nullspace Dimension Formula

$$\dim(N(A)) = n - r$$
Nullspace dimension

This is half of the Rank-Nullity theorem: $\text{rank}(A) + \text{nullity}(A) = n$.

3.3 Example Special Solutions

$$\text{Given RREF: } \begin{bmatrix} 1 & -2 & 0 & 3 \\ 0 & 0 & 1 & 4 \end{bmatrix}$$ $$\text{Special solution 1 } (x_2=1, x_4=0): \quad \mathbf{x}_1 = \begin{bmatrix} 2 \\ 1 \\ 0 \\ 0 \end{bmatrix}$$ $$\text{Special solution 2 } (x_2=0, x_4=1): \quad \mathbf{x}_2 = \begin{bmatrix} -3 \\ 0 \\ -4 \\ 1 \end{bmatrix}$$
Two special solutions spanning $N(A)$

3.4 Nullspace Properties

  • The nullspace always contains the zero vector
  • The nullspace is closed under addition and scalar multiplication
  • If no free variables exist, nullspace = $\{0\}$ only

4. Solving $A\mathbf{x} = \mathbf{b}$: Row Reduced Form

Complete solutions to non-homogeneous systems. This section extends the nullspace theory to solve $A\mathbf{x} = \mathbf{b}$ completely, identifying conditions for existence and describing the full solution set.

4.1 Complete Solution Structure

The complete solution to $A\mathbf{x} = \mathbf{b}$ has the form $\mathbf{x} = \mathbf{x}_p + \mathbf{x}_{\text{nullspace}}$. One particular solution $\mathbf{x}_p$ satisfies $A\mathbf{x}_p = \mathbf{b}$. Adding any nullspace vector $\mathbf{x}_n$ (where $A\mathbf{x}_n = \mathbf{0}$) gives another solution. The full solution set is an affine subspace.

4.2 Existence Conditions

$A\mathbf{x} = \mathbf{b}$ has a solution if and only if $\mathbf{b}$ is in $C(A)$. Equivalently, $\text{rank}(A) = \text{rank}([A|\mathbf{b}])$. If the augmented matrix has an extra nonzero row compared to $A$, the system is inconsistent.

4.3 Particular Solutions

To find one particular solution, set all free variables to zero in the RREF of $[A|\mathbf{b}]$. The pivot variables are then determined by the rightmost column of the reduced augmented matrix.

4.4 Inconsistency Detection

Key Rule: "0 = 0 is OK, 0 = c is Not"
In the RREF of $[A|\mathbf{b}]$, a row of all zeros in $A$ is fine. But if that row has a nonzero entry in the $\mathbf{b}$-column, the system is inconsistent (no solution).

5. Independence, Basis & Dimension

Linear independence, basis vectors, and dimension theory. This section defines the fundamental concepts that measure the "size" and structure of vector spaces and subspaces.

5.1 Linear Independence

A set of vectors $\{\mathbf{v}_1, \ldots, \mathbf{v}_k\}$ is linearly independent if the only solution to $c_1\mathbf{v}_1 + \cdots + c_k\mathbf{v}_k = \mathbf{0}$ is $c_1 = \cdots = c_k = 0$. If any nonzero coefficients produce zero, the vectors are dependent.

5.2 Testing Independence

$$\text{Form } A = [\mathbf{v}_1 \; \mathbf{v}_2 \; \cdots \; \mathbf{v}_k]$$ $$\text{Solve } A\mathbf{x} = \mathbf{0}$$ $$\text{If only trivial solution } \mathbf{x} = \mathbf{0}: \text{ independent}$$ $$\text{If nontrivial solution exists: dependent}$$
Independence test via matrix

The vectors are independent exactly when $\text{rank}(A) = k$.

5.3 Basis

A basis for a vector space $V$ is a set of vectors that are both linearly independent and span $V$. Every vector in $V$ can be written uniquely as a linear combination of basis vectors.

5.4 Dimension

The dimension of a vector space is the number of vectors in any basis for that space. All bases for a given space have the same number of vectors. $\dim(\mathbb{R}^n) = n$. The dimension of a subspace is less than or equal to the dimension of the parent space.

5.5 Rank

The rank of a matrix is the dimension of its column space (or row space). The rank equals the number of pivot columns. It measures how much "information" the matrix preserves.

Basis = Just Right: A basis has exactly the right number of vectors: enough to span the space, but not so many that they become dependent. Not too few (can't span), not too many (dependent).
