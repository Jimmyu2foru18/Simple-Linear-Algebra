1. Singular Value Decomposition (SVD)

The SVD is one of the most important matrix factorizations in linear algebra. Every $m \times n$ matrix $A$ can be factored as $A = U\Sigma V^T$.

1.1 The SVD Factorization

$$A = U\Sigma V^T$$
Singular Value Decomposition
  • $U$: $m \times m$ orthogonal matrix (left singular vectors)
  • $\Sigma$: $m \times n$ diagonal matrix with nonnegative singular values $\sigma_1 \geq \sigma_2 \geq \cdots \geq \sigma_r > 0$
  • $V$: $n \times n$ orthogonal matrix (right singular vectors)

1.2 Key Properties

  • The columns of $U$ are eigenvectors of $AA^T$
  • The columns of $V$ are eigenvectors of $A^TA$
  • $\sigma_i = \sqrt{\lambda_i}$ where $\lambda_i$ are eigenvalues of $A^TA$
  • Rank of $A$ = number of nonzero singular values

1.3 Applications

  • Image compression (keeping top $k$ singular values)
  • Principal Component Analysis (PCA)
  • Solving ill-conditioned systems (truncated SVD)
  • Recommendation systems

2. Symmetric Matrices & Positive Definiteness

A matrix $A$ is symmetric if $A = A^T$. Symmetric matrices have particularly nice properties, including real eigenvalues and orthogonal eigenvectors.

2.1 Spectral Theorem

Spectral Theorem: Every symmetric matrix $A$ can be diagonalized by an orthogonal matrix: $A = Q\Lambda Q^T$, where $Q$ is orthogonal and $\Lambda$ is diagonal with real eigenvalues.

2.2 Positive Definite Matrices

PropertyEquivalent Conditions
Positive Definite$\mathbf{x}^TA\mathbf{x} > 0$ for all $\mathbf{x} \neq \mathbf{0}$
EigenvaluesAll eigenvalues $\lambda_i > 0$
PivotsAll pivots in Gaussian elimination are positive
DeterminantsAll leading principal minors are positive
Square root$A = B^TB$ for some invertible $B$

3. Moore-Penrose Pseudoinverse

The pseudoinverse $A^+$ generalizes the inverse to rectangular or singular matrices. It provides the least squares solution to $A\mathbf{x} = \mathbf{b}$.

3.1 Definition via SVD

$$A^+ = V\Sigma^+U^T$$
Pseudoinverse via SVD

where $\Sigma^+$ is formed by taking the reciprocal of each nonzero singular value in $\Sigma$ and transposing the result.

3.2 Properties

  • $AA^+A = A$
  • $A^+AA^+ = A^+$
  • $(AA^+)^T = AA^+$
  • $(A^+A)^T = A^+A$
  • The least squares solution is $\mathbf{x} = A^+\mathbf{b}$
