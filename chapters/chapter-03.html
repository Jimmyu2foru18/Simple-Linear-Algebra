Detailed Topic Breakdowns

Matrix Multiplication

Matrix multiplication is defined by taking the dot product of rows of the first matrix with columns of the second. The product AB exists only when the number of columns of A equals the number of rows of B.

Inverse of a Matrix

A square matrix A has an inverse A^-1 if there exists a matrix such that AA^-1 = A^-1A = I. Not all square matrices are invertible - those that are not are called singular or degenerate.

Diagonal and Elimination Matrices

Diagonal matrices have nonzero entries only on the main diagonal. They are easy to invert: simply invert each diagonal entry. Elimination matrices perform row operations and their inverses reverse those operations.

Gauss-Jordan Elimination

By augmenting A with the identity matrix [A | I] and reducing to [I | A^-1], we can compute the inverse directly. If A cannot be reduced to the identity, it is singular.

Derivation: Properties of Matrix Inverses

Key algebraic properties:

$$(AB)^-1 = B^-1 * A^-1 (reverse order!) (A^-1)^-1 = A (A^T)^-1 = (A^-1)^T (A + B)^-1 â‰  A^-1 + B^-1 (warning: does not distribute!)$$

The reversal of order in (AB)^-1 = B^-1 A^-1 is crucial: you st undo the last operation first when inverting a product.

Learning Strategies

Mnemonic Devices

Mnemonic: "S-O-S" - Same Order, Switch, Swap

For a 2x2 inverse: Same diagonal entries stay, Off-diagonals switch positions, Swap signs of off-diagonals, then divide by determinant.

Mnemonic: "Last In, First Out" for Inverses

When inverting a product AB, undo B first (B^-1), then undo A (A^-1). This is why (AB)^-1 = B^-1 A^-1.

Study Tips

  • Always check dimensions before ltiplying - incompatible sizes mean the product doesn't exist
  • Memorize the 2x2 inverse forla; for larger matrices, use Gauss-Jordan
  • Verify inverses by checking AA^-1 = I, not just A^-1A = I
  • Remember: a zero determinant means singularity and no inverse
  • Practice with pertation matrices - their inverses are their transposes

Example 1: Matrix Multiplication

Problem: Compute AB and BA and determine if they are equal.

$$A = [1 2] B = [3 0]$$ [0 1] [1 4]

Solution:

$$AB = [1*3+2*1 1*0+2*4] = [5 8]$$ [0*3+1*1 0*0+1*4] [1 4] $$BA = [3*1+0*0 3*2+0*1] = [3 6]$$ [1*1+4*0 1*2+4*1] [1 6]

Example 2: Finding an Inverse

Problem: Find A^-1 using the forla and verify.

$$A = [2 3]$$ [1 2]

Solution:

  1. Determinant: $\det(A)$ = 2*2 - 3*1 = 1
  2. Apply forla: A^-1 = [[2, -3], [-1, 2]]
  3. Verify: [[2,3],[1,2]] * [[2,-3],[-1,2]] = [[1,0],[0,1]] âœ“

Example 3: Singular Matrix

Problem: Show that A = [[1, 2], [2, 4]] has no inverse.

Solution:

  • Determinant: 1*4 - 2*2 = 4 - 4 = 0
  • Row 2 = 2 * Row 1
  • Columns are linearly dependent
  • Rank = 1 < 2, so A is singular
  • No inverse exists.
