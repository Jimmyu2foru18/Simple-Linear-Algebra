Detailed Topic Breakdowns

Matrix Spaces

The set of all m x n matrices forms a vector space M with dimension mn. Addition and scalar multiplication are defined entrywise. Subspaces include symmetric matrices, triangular matrices, and diagonal matrices, each with their own dimensions.

Rank-1 Matrices

A rank-1 matrix can be written as the outer product uv^T of two vectors. Every matrix of rank r can be expressed as a sum of r rank-1 matrices. Rank-1 matrices are the "building blocks" of all matrices.

Small World Graphs

The "small world phenomenon" describes how most networks have surprisingly short paths between nodes. Graph theory models these networks, and linear algebra provides tools to analyze their structure through adjacency matrices and their powers.

Adjacency Matrices

An adjacency matrix A represents a graph where A_ij = 1 if there is an edge from node i to node j, and 0 otherwise. The matrix powers A^k count the number of walks of length k between nodes.

Computation Examples

Derivation: Rank-1 Factorization

Any rank-1 matrix A has columns that are multiples of each other:

$$A = [\mathbf{u} \ c_2\mathbf{u} \ \cdots \ c_n\mathbf{u}] \quad \text{where } \mathbf{u} \text{ is a column vector}$$

This can be written as: $$A = \mathbf{u} \begin{bmatrix} c_1 & c_2 & \cdots & c_n \end{bmatrix} = \mathbf{u}\mathbf{v}^T \quad \text{(outer product)}$$

The dimension of the space of rank-1 matrices in M_{m \times n} is m + n - 1 (m for u, n for v, minus 1 for scaling ambiguity).

Derivation: Counting Walks via Matrix Powers

The (i, j) entry of A^k counts walks of length k from node i to node j:

The (i, j) entry of A^k counts walks of length k from node i to node j:

$$(A^2)_{ij} = \sum_{\ell} A_{i\ell} A_{\ell j} = \text{number of 2-step paths } i \to \ell \to j$$ $$(A^k)_{ij} = \sum_{\substack{\text{paths} \\ i = v_0 \to v_1 \to \cdots \to v_k = j}} 1$$

This connects linear algebra to network analysis.

Learning Strategies

Mnemonic Devices

Mnemonic: "Rank 1 = Column Times Row"

Every rank-1 matrix is an outer product: one column vector times one row vector. Think of it as stretching a single direction across the entire space.

Mnemonic: "Matrix Space Dimensions multiply"

The space of m x n matrices has dimension m — n. Symmetric matrices: n(n+1)/2. Diagonal matrices: n. Upper triangular: n(n+1)/2.

Study Tips

  • Practice constructing rank-1 matrices from given vectors
  • Understand that any matrix can be decomposed into a sum of rank-1 matrices (SVD)
  • When analyzing graphs, start by drawing them before building the adjacency matrix
  • Remember: A^k counts walks, not just shortest paths
  • The small world property often emerges in sparse graphs with few long-range connections

Worked Examples

Example 1: Rank-1 Matrix Decomposition

Problem: Express A = [[2, 4, 6], [1, 2, 3]] as a rank-1 matrix uv^T.

Solution:

  1. Note column 2 = 2 * column 1, column 3 = 3 * column 1
  2. Rank = 1
  3. Take u = [2, 1]^T (first column)
  4. Take v = [1, 2, 3] (row multipliers)
  5. A = [2, 1]^T * [1, 2, 3] = [[2, 4, 6], [1, 2, 3]] ✓

Example 2: Matrix Space Dimension

Problem: What is the dimension of the subspace of 3x3 skew-symmetric matrices?

Solution:

  • Skew-symmetric: A^T = -A, so a_ii = 0 and a_ji = -a_ij
  • Free parameters: a_12, a_13, a_23 (3 parameters)
  • Dimension = 3 = n(n-1)/2 for n=3

Practice Problems

Problem Set 11

Problem 1: Write A = [[1, 3, 5], [2, 6, 10]] as uv^T.

Hint: Identify the column direction and the scaling row.

Solution

u = [1, 2]^T, v = [1, 3, 5]

A = [1, 2]^T * [1, 3, 5]

Problem 2: What is the dimension of the space of 4x4 symmetric matrices?

Hint: Count the free entries in the upper triangle including the diagonal.

Solution

4 + 3 + 2 + 1 = 10. Formula: n(n+1)/2 = 4(5)/2 = 10.

Problem 3: Can every 2x2 matrix be written as a sum of two rank-1 matrices? Explain.

Hint: The maximum rank of a 2x2 matrix is 2.

Solution

Yes. Any 2x2 matrix A has rank ≠ 2. If rank = 2, it can be written as a sum of two rank-1 matrices (e.g., via SVD or by column splitting). If rank = 1, it is already one rank-1 matrix (add zero matrix).

Problem 4: For a graph with adjacency matrix A, what does (A^3)_ii represent?

Hint: Count closed walks of length 3 starting and ending at node i.

Solution

(A^3)_ii counts the number of closed walks of length 3 starting and ending at node i. This is useful for analyzing clustering in networks.
