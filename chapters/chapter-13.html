Detailed Topic Breakdowns

Exam Emphasis: Chapter 3

The exam will emphasize Chapter 3, where rectangular matrices make the theory interesting. When matrices are square and invertible, null spaces and ranks are straightforward. For rectangular matrices, these same concepts become the central objects of study. Focus on null spaces of A and AT, rank, and above all, the four subspaces.

Vector Spaces and Subspaces

A subspace is a vector space contained within another vector space. The key test: a set S is a subspace if it contains the zero vector, and is closed under addition and scalar multiplication. Every spanning set generates a subspace, and the dimension of that subspace is the number of vectors in a basis for it.

Dimensions of Spanned Subspaces

If nonzero vectors u, v, w in $\mathbb{R}^7$ span a subspace, the possible dimensions are 1, 2, or 3. It cannot be 0 because the vectors are nonzero. It cannot exceed 3 because only three vectors are available. The actual dimension equals the number of linearly independent vectors among them.

The Four Subspaces

For any matrix A, the four fundamental subspaces are:

  • Column Space C(A): In $\mathbb{R}^m$, dimension r. All combinations of columns.
  • Null Space N(A): In $\mathbb{R}^n$, dimension $n-r$. All solutions to $Ax = 0$.
  • Row Space C(AT): In $\mathbb{R}^n$, dimension r. All combinations of rows.
  • Left Null Space N(AT): In $\mathbb{R}^m$, dimension $m-r$. All solutions to $A^T y = 0$.

The row space and column space share the same dimension (the rank). Each pair of orthogonal complements sums to the full space dimension.

Null Spaces and Echelon Form

For a matrix in echelon form with r pivots, the rank is r. The null space has dimension $n - r$. If rank equals the number of columns, the null space contains only the zero vector. If rank is less than full, the free variables produce special solutions that form a basis for the null space.

Full Rank Cases

Two critical full-rank cases are $r = m$ (full row rank) and $r = n$ (full column rank). When $r = n$, the columns are independent and $N(A) = \{0\}$. When $r = m$, the rows are independent and $N(A^T) = \{0\}$. For a square invertible matrix, both hold simultaneously.

Mathematical Rigor

Derivation: Dimensions of a Spanned Subspace

For three nonzero vectors in $\mathbb{R}^7$, the subspace they span has dimension equal to the number of linearly independent vectors:

$$dim(span\{u, v, w\}) = \text{number of independent vectors among } u, v, w$$

Since we have three vectors and they are nonzero, the dimension $d$ satisfies $1 \leq d \leq 3$.

Derivation: Null Space of an Echelon Form Matrix

For a $5 \times 3$ matrix U in echelon form with three pivots ($r = 3$):

$$U = \begin{bmatrix} \times & \times & \times \\ 0 & \times & \times \\ 0 & 0 & \times \\ 0 & 0 & 0 \\ 0 & 0 & 0 \end{bmatrix}$$

Since rank $r = 3$ equals the number of columns $n = 3$, the columns are independent. The equation $Ux = 0$ has only the trivial solution $x = [0, 0, 0]^T$.

$$N(U) = \{0\} \quad \text{and} \quad dim(N(U)) = n - r = 3 - 3 = 0$$

Derivation: Rank of Block Matrices

Consider the block matrix $C = \begin{bmatrix} U & U & U & 0 \end{bmatrix}$ where U is $10 \times 3$ and in reduced row echelon form. The matrix C is $10 \times 6$. Row reduction on block matrices operates row by row:

$$C \xrightarrow{\text{row reduction}} \begin{bmatrix} R & R & R & 0 \end{bmatrix}$$

where R is the reduced echelon form of U. Since the three R blocks each contribute 3 independent rows, the total rank is $3 + 3 = 6$.

$$rank(C) = 6$$

For $C^T$, which is $6 \times 10$, the dimension of the null space is:

$$dim(N(C^T)) = m - rank(C) = 10 - 6 = 4$$

Learning Strategies

Mnemonic Devices

Mnemonic: "Rank = Pivots = Independent Columns"

The rank of a matrix equals its number of pivots, which equals the number of independent columns and independent rows. This single number determines the dimensions of all four subspaces.

Mnemonic: "Four Subspaces: Row and Column, Left and Right"

Pair them by dimension: $C(A)$ pairs with $N(A^T)$ in $\mathbb{R}^m$; $C(A^T)$ pairs with $N(A)$ in $\mathbb{R}^n$. Each pair are orthogonal complements.

Mnemonic: "Null Space: Free Variables = Special Solutions"

The dimension of the null space equals the number of free variables. Each free variable produces one special solution. Set one free variable to 1, others to 0, and solve for pivot variables.

Study Tips

  • Always identify the matrix dimensions m, n, and rank r first
  • Use the dimension formulas: $dim(C(A)) = r$, $dim(N(A)) = n-r$, $dim(C(A^T)) = r$, $dim(N(A^T)) = m-r$
  • For block matrices, think about how row operations affect each block separately
  • When given a complete solution, the particular solution reveals a column of A and the null space basis reveals other columns
  • True/false questions about subspaces: test the three subspace conditions (zero vector, closed under add, closed under scalar mult)

Figure: The Four Subspaces Orthogonality

The Fundamental Theorem of Linear Algebra visualized:

$$\mathbb{R}^m: \quad C(A) \perp N(A^T), \quad dim(C(A)) = r, \quad dim(N(A^T)) = m-r$$ $$\mathbb{R}^n: \quad C(A^T) \perp N(A), \quad dim(C(A^T)) = r, \quad dim(N(A)) = n-r$$

The row space and column space share dimension r. Each pair forms orthogonal complements in their respective spaces.

Worked Examples

Example 1: Dimensions of a Spanned Subspace

Problem: Suppose $u, v, w$ are nonzero vectors in $\mathbb{R}^7$. What are the possible dimensions of the subspace they span?

Solution:

  • The dimension cannot be 0 because the vectors are nonzero
  • The dimension cannot exceed 3 because only 3 vectors are available
  • Possible dimensions: 1, 2, or 3
  • Dim = 1 if all are multiples of one vector
  • Dim = 2 if exactly two are independent
  • Dim = 3 if all three are independent

Example 2: Null Space of an Echelon Form Matrix

Problem: Let U be a $5 \times 3$ matrix in echelon form with $r = 3$ pivots. What is $N(U)$?

Solution:

  • Rank $r = 3$ equals the number of columns $n = 3$
  • All three columns are linearly independent
  • The equation $Ux = 0$ has only the trivial solution
  • $N(U) = \{[0, 0, 0]^T\}$
  • $dim(N(U)) = n - r = 3 - 3 = 0$

Example 3: Rank of a Block Matrix

Problem: Let $B = \begin{bmatrix} U \\ U \end{bmatrix}$ where U is $5 \times 3$ in reduced echelon form with $r = 3$. What is the rank of B?

Solution:

  • B is a $10 \times 3$ matrix formed by stacking two copies of U
  • Row reduction on the top half produces R, and the bottom half is identical
  • The bottom half adds no new independent rows
  • $rank(B) = 3$ (same as U)

Example 4: Complete Solution Recovery

Problem: The complete solution to $Ax = \begin{bmatrix} 2 \\ 4 \\ 2 \end{bmatrix}$ is given by $x = \begin{bmatrix} 1 \\ 0 \\ 0 \end{bmatrix} + c_1 \begin{bmatrix} -1 \\ -2 \\ -1 \end{bmatrix} + c_2 \begin{bmatrix} 0 \\ 0 \\ 1 \end{bmatrix}$. Find the rank, null space, and column space of A.

Solution:

  • Null space dimension: Two independent null space vectors $\Rightarrow dim(N(A)) = 2$
  • Rank: If A is $3 \times 3$, then $rank(A) = n - dim(N(A)) = 3 - 2 = 1$
  • First column of A: $A \begin{bmatrix} 1 \\ 0 \\ 0 \end{bmatrix} = \begin{bmatrix} 2 \\ 4 \\ 2 \end{bmatrix}$ means the first column is $\begin{bmatrix} 1 \\ 2 \\ 1 \end{bmatrix}$
  • Second column: Since $\begin{bmatrix} -1 \\ -2 \\ -1 \end{bmatrix} \in N(A)$, the second column is $-\begin{bmatrix} 1 \\ 2 \\ 1 \end{bmatrix} = \begin{bmatrix} -1 \\ -2 \\ -1 \end{bmatrix}$
  • Third column: Since $\begin{bmatrix} 0 \\ 0 \\ 1 \end{bmatrix} \in N(A)$, the third column is $\begin{bmatrix} 0 \\ 0 \\ 0 \end{bmatrix}$
  • Matrix: $A = \begin{bmatrix} 1 & -1 & 0 \\ 2 & -2 & 0 \\ 1 & -1 & 0 \end{bmatrix}$
  • Column space: $C(A) = span\left\{\begin{bmatrix} 1 \\ 2 \\ 1 \end{bmatrix}\right\}$, all multiples of $\begin{bmatrix} 1 \\ 2 \\ 1 \end{bmatrix}$
  • Solvability: $Ax = b$ can be solved if and only if $b$ is a multiple of $\begin{bmatrix} 1 \\ 2 \\ 1 \end{bmatrix}$

Practice Problems

Problem Set 13

Problem 1: Let $u, v, w$ be nonzero vectors in $\mathbb{R}^7$. What are the possible dimensions of the subspace they span? Justify each possibility.

Hint: Dimension cannot exceed the number of vectors, and cannot be zero because the vectors are nonzero.

Solution

The possible dimensions are 1, 2, or 3.

  • Dim = 1: All three vectors lie on the same line (all are scalar multiples of one vector)
  • Dim = 2: Two vectors are independent, the third is a linear combination
  • Dim = 3: All three vectors are linearly independent

Problem 2: Let U be a $5 \times 3$ matrix in echelon form with three pivots. What is the null space of U? What is its dimension?

Hint: Compare the rank to the number of columns.

Solution

Since $rank(U) = 3$ and $n = 3$, there are no free variables.

$N(U) = \{[0, 0, 0]^T\}$

$dim(N(U)) = n - r = 3 - 3 = 0$

Problem 3: Let $B = \begin{bmatrix} U \\ U \end{bmatrix}$ and $C = \begin{bmatrix} U & U & U & 0 \end{bmatrix}$, where U is $10 \times 3$ in reduced row echelon form with $rank(U) = 3$. Find the rank of B and the rank of C.

Hint: For block matrices, row reduction acts on each block. Stacking duplicates rows; horizontal concatenation adds columns.

Solution

Rank of B: B is $20 \times 3$. The top block U already has rank 3 (full column rank). The bottom block U adds no new independent rows. $rank(B) = 3$.

Rank of C: C is $10 \times 6$. The three U blocks each contribute 3 independent columns, while the zero block contributes nothing. Since the three U blocks provide 6 independent columns total, $rank(C) = 6$.

Problem 4: True or False: The set of invertible $5 \times 5$ matrices forms a subspace of the vector space of all $5 \times 5$ matrices. Explain.

Hint: Check whether the zero matrix is invertible, and whether the sum of two invertible matrices is always invertible.

Solution

False. The zero matrix is not invertible, so the set fails the "contains zero vector" subspace test. Also, the sum of two invertible matrices can be singular. For example, $I + (-I) = 0$, which is not invertible.

Problem 5: Let A be an $m \times n$ matrix. Prove that the null space of A is perpendicular to the row space of A.

Hint: If $x \in N(A)$, then $Ax = 0$. Every row of A dotted with $x$ equals 0.

Solution

If $x \in N(A)$, then $Ax = 0$. This means every row $r_i$ of A satisfies $r_i \cdot x = 0$. Therefore $x$ is orthogonal to every row of A, so $x$ is orthogonal to every vector in the row space $C(A^T)$. Thus $N(A) \perp C(A^T)$.
