Detailed Topic Breakdowns

Dot Product and Orthogonality

The dot product (inner product) of vectors u and v in \$\mathbb{R}^n\$ is u Â· v = u^T v = sum(u_i * v_i). Vectors are orthogonal when their dot product is zero. The length (norm) of a vector is ||v|| = sqrt(v Â· v).

Orthogonal Subspaces

Two subspaces V and W are orthogonal if every vector in V is orthogonal to every vector in W. The orthogonal complement V^perp is the set of all vectors orthogonal to V. Key fact: (V^perp)^perp = V for closed subspaces.

Projections onto Lines and Subspaces

The projection of a vector b onto a line through a is p = (a^T b / a^T a) * a. For a subspace with orthonormal basis columns in Q, the projection is p = Q Q^T b. Projections minimize the distance from b to the subspace.

Least Squares Approximation

When \\mathbf{x} = \mathbf{b}\$ has no exact solution, the least squares solution minimizes ||Ax - b||. The normal equations are A^T A x = A^T b. If A has independent columns, A^T A is invertible and x = (A^T A)^-1 A^T b.

Orthogonal Matrices

An orthogonal matrix Q satisfies Q^T Q = I, meaning its columns are orthonormal. Orthogonal matrices preserve lengths and angles: ||Qx|| = ||x||. Their inverses equal their transposes: Q^-1 = Q^T.

Gram-Schmidt Orthogonalization

The Gram-Schmidt process takes any set of independent vectors and produces an orthonormal basis for their span. At each step, subtract the projection of the new vector onto all previously processed vectors, then normalize.

Mathematical Rigor

Derivation: Projection Formula

To project b onto the line through a, we seek p = c*a such that the error e = b - p is orthogonal to a:

\$\$a^T e = 0 $$a^T (b - ca) = 0 a^T b - c(a^T a) = 0 c = (a^T b) / (a^T a)$$ $$Therefore: p = ((a^T b) / (a^T a)) * a\$\$$$

Derivation: Least Squares via Projection

We want Ax â‰ˆ b. The closest point in C(A) to b is the projection p = A x_hat. Since the error e = b - Ax_hat is orthogonal to C(A), it is orthogonal to every column of A:

\$\$A^T (b - Ax_hat) = 0 $$A^T b - A^T A x_hat = 0 A^T A x_hat = A^T b (Normal Equations)\$\$$$

Derivation: Gram-Schmidt Process

Given independent vectors a1, a2, ..., an:

\$\$Step 1: q1 = a1 / ||a1|| $$Step 2: q2 = (a2 - (q1^T a2)q1) / ||a2 - (q1^T a2)q1|| Step 3: q3 = (a3 - (q1^T a3)q1 - (q2^T a3)q2) / ||...||$$ ... $$Step k: qk = (ak - sum_{j=1}^{k-1} (qj^T ak)qj) / ||...||\$\$$$

Each qk is orthogonal to all previous qj and has unit length.

Learning Strategies

Mnemonic Devices

Mnemonic: "Project then Subtract"

To find the closest point to b in a subspace: (1) project b onto the subspace to get p, (2) subtract to get the error e = b - p. The error is orthogonal to the subspace.

Mnemonic: "Gram-Schmidt: Subtract Projections, Then Normalize"

For each vector: remove its shadow on previous vectors (subtract projections), then scale to unit length (normalize). The result is an orthonormal basis.

Mnemonic: "Least Squares = Closest in Column Space"

When \\mathbf{x} = \mathbf{b}\$ has no solution, find x_hat that makes Ax_hat as close to b as possible. This is the projection of b onto C(A).

Study Tips

  • Always draw the projection picture: b decomposes into p (in subspace) + e (orthogonal to subspace)
  • For projections onto lines, memorize p = (a^T b / a^T a) a
  • QR factorization from Gram-Schmidt makes least squares easy: R x = Q^T b
  • Orthogonal matrices preserve geometry - rotations and reflections
  • The normal equations A^T A x = A^T b are the key to least squares
  • Check A^T A is invertible: requires independent columns of A

Worked Examples

Example 1: Projection onto a Line

Problem: Project b = [3, 2]^T onto the line through a = [1, 1]^T.

Solution:

  1. a^T a = 1 + 1 = 2
  2. a^T b = 3 + 2 = 5
  3. p = (5/2) * [1, 1]^T = [2.5, 2.5]^T
  4. Error: e = [3, 2]^T - [2.5, 2.5]^T = [0.5, -0.5]^T
  5. Check: a Â· e = 1*0.5 + 1*(-0.5) = 0 âœ“

Example 2: Least Squares Fit

Problem: Find the least squares line y = C + Dt through points (t, y) = (1, 1), (2, 2), (3, 2).

Solution:

  1. Design matrix: A = [[1, 1], [1, 2], [1, 3]], b = [1, 2, 2]^T
  2. A^T A = [[3, 6], [6, 14]]
  3. A^T b = [5, 11]^T
  4. Normal equations: [[3, 6], [6, 14]] [C, D]^T = [5, 11]^T
  5. Solve: C = 1/3, D = 3/2
  6. Best fit line: y = 1/3 + (3/2)t

Example 3: Gram-Schmidt Process

Problem: Orthonormalize a1 = [1, 1, 0]^T, a2 = [1, 0, 1]^T, a3 = [1, 1, 1]^T.

Solution:

  1. q1 = [1, 1, 0]^T / sqrt(2) = [1/sqrt(2), 1/sqrt(2), 0]^T
  2. Project a2 onto q1: (q1^T a2) = 1/sqrt(2)
  3. a2_perp = [1, 0, 1]^T - (1/sqrt(2))[1/sqrt(2), 1/sqrt(2), 0]^T = [0.5, -0.5, 1]^T
  4. ||a2_perp|| = sqrt(0.25 + 0.25 + 1) = sqrt(1.5)
  5. q2 = [0.5, -0.5, 1]^T / sqrt(1.5)
  6. Similarly compute q3 from a3 minus projections onto q1 and q2
