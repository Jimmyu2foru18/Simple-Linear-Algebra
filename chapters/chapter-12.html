Detailed Topic Breakdowns

Incidence Matrices

An incidence matrix A represents a graph with n nodes and m edges. Each row corresponds to an edge, with +1 and -1 entries indicating the nodes it connects. For undirected graphs, the orientation is arbitrary.

Kirchhoff's Laws

Kirchhoff's Current Law (KCL) states that flow into a node equals flow out. Kirchhoff's Voltage Law (KVL) states that voltage differences around any loop sum to zero. These laws are elegantly expressed using incidence matrices.

Rank of Incidence Matrices

For a connected graph with n nodes, the incidence matrix has rank n-1. One row is always dependent because the sum of all rows is zero. The nullspace of A^T corresponds to vectors satisfying KCL.

Spanning Trees and Independence

A spanning tree of a graph with n nodes has exactly n-1 edges and connects all nodes without cycles. The columns of A corresponding to a spanning tree are independent. The remaining edges form cycles.

Learning Strategies

Mnemonic Devices

Mnemonic: "Incidence: In for +1, Out for -1"

In an incidence matrix, the row for edge (i, j) has +1 at column i (head) and -1 at column j (tail). This records the direction of flow across each edge.

Mnemonic: "Tree Gives Independence, Loop Gives Dependency"

Spanning tree edges give independent columns in A. Adding one more edge creates one cycle and one dependency. Number of independent cycles = m - n + 1.

Study Tips

  • Always draw the graph before constructing the incidence matrix
  • Check that row sums of A are zero as a consistency check
  • For KCL, the nullspace of A^T gives loop currents
  • A spanning tree has n-1 edges for n nodes
  • Removing any edge from a cycle creates a spanning tree

Worked Examples

Example 1: Constructing an Incidence Matrix

Problem: Build the incidence matrix for a triangle graph with nodes 1, 2, 3 and edges (1,2), (2,3), (3,1).

Solution:

\$\$n1 n2 n3 $$e12: 1 -1 0 e23: 0 1 -1 e31: -1 0 1 (or reverse: 1 0 -1)$$ Note: Each column sums to 0 (KCL at each node if no external current).\$\$

Example 2: Finding the Rank

Problem: Determine the rank of the incidence matrix for a tree with 5 nodes.

Solution:

  • A tree with n nodes has n-1 edges and no cycles
  • Incidence matrix: (n-1) x n = 4x5
  • For a connected tree, rank = n-1 = 4
  • One nullspace vector in R^5: [1, 1, 1, 1, 1]^T

Practice Problems

Problem Set 12

Problem 1: For a graph with 6 nodes and 9 edges, how many independent cycles does it have?

Hint: Use the cycle rank formula m - n + c where c is the number of connected components.

Solution

Assuming connected (c=1): cycles = 9 - 6 + 1 = 4. dim(N(A^T)) = 4.

Problem 2: Show that for any incidence matrix, the vector [1, 1, ..., 1]^T is in the nullspace of A.

Hint: Each row of A has one +1 and one -1.

Solution

Row i of A has exactly one +1 and one -1. When multiplied by [1, ..., 1]^T, the result is 1 + (-1) = 0. Thus A * 1 = 0.

Problem 3: What is the dimension of the row space of the incidence matrix for a connected graph with n nodes?

Hint: The row space is the column space of A^T.

Solution

dim(row space) = dim(C(A^T)) = \$\text{rank}(A)\$ = n-1.

Problem 4: In an electrical network, if node 1 has external current +3 and node 2 has -3, write the KCL equation \\mathbf{x} = \mathbf{b}\$.

Hint: b represents external current injection at each node.

Solution

b = [3, -3, 0, 0, ...]^T. The incidence matrix A multiplied by edge currents x must equal b, ensuring current conservation at each node.
