Detailed Topic Breakdowns

Complete Solution Structure

The complete solution to $A\mathbf{x} = \mathbf{b}$ has the form x = x_particular + x_nullspace. One particular solution x_p satisfies Ax_p = b. Adding any nullspace vector x_n (where Ax_n = 0) gives another solution. The full solution set is an affine subspace.

Existence Conditions

$A\mathbf{x} = \mathbf{b}$ has a solution if and only if b is in C(A). Equivalently, $\text{rank}(A)$ = rank([A | b]). If the augmented matrix has an extra nonzero row compared to A (e.g., [0 ... 0 | nonzero]), the system is inconsistent.

Row Reduced Form R

R is the RREF of A. It reveals pivot and free variables and makes the structure of solutions transparent. The RREF of [A | b] directly shows whether a solution exists and provides a particular solution.

Particular Solutions

To find one particular solution, set all free variables to zero in the RREF of [A | b]. The pivot variables are then determined by the rightmost column of the reduced augmented matrix.

Mathematical Rigor

Derivation: The General Solution

Let x_p be any particular solution to $A\mathbf{x} = \mathbf{b}$. For any x_n ∈ N(A):

$$A(x_p + x_n) = Ax_p + Ax_n = b + 0 = b $$Therefore, x_p + x_n is also a solution.$$ Conversely, if x is any solution: $$A(x - x_p) = Ax - Ax_p = b - b = 0 So x - x_p ∈ N(A), meaning x = x_p + x_n for some x_n.$$

This proves the complete solution is exactly the particular solution plus the entire nullspace.

Derivation: Inconsistency Detection

After row reduction, if any row of [R | d] has the form [0 0 ... 0 | c] where c ≈  0, then:

$$0*x1 + 0*x2 + ... + 0*xn = c $$0 = c (impossible!)$$ $$This means b ∉ C(A), so $A\mathbf{x} = \mathbf{b}$ has no solution.$$

Learning Strategies

Mnemonic Devices

Mnemonic: "One Particular Plus All Nullspace"

The complete solution is not just one answer - it's one particular solution plus the entire nullspace. Think of it as: "Find one solution, then add all the ways to get zero."

Mnemonic: "0 = 0 is OK, 0 = c is Not"

In the RREF of [A | b], a row of all zeros in A is fine. But if that row has a nonzero entry in the b-column, the system is inconsistent (no solution).

Study Tips

  • Always check consistency first by comparing $\text{rank}(A)$ and rank([A | b])
  • When finding a particular solution, set free variables to zero
  • Write the complete solution as: x = x_p + c1*v1 + c2*v2 + ...
  • Verify by substituting the particular solution back into $A\mathbf{x} = \mathbf{b}$
  • The number of special solutions equals the number of free variables

Worked Examples

Example 1: Consistent System

Problem: Solve $A\mathbf{x} = \mathbf{b}$ completely for:

$$A = [[1, 2, 2], [2, 4, 6]] b = [1, 5]^T$$

Solution:

  1. RREF of [A | b]: [[1, 2, 2 | 1], [0, 0, 2 | 3]]
  2. Consistent (no 0 = nonzero row)
  3. Pivot variables: x1, x3. Free: x2
  4. Particular solution (x2 = 0): x1 = -3, x3 = 1.5
  5. Special solution (x2 = 1): x1 = -2, x3 = 0
  6. Complete: x = [-3, 0, 1.5]^T + c*[-2, 1, 0]^T

Example 2: Inconsistent System

Problem: Determine if $A\mathbf{x} = \mathbf{b}$ has a solution for:

$$A = [[1, 2], [2, 4]] b = [3, 7]^T$$

Solution:

  • RREF of [A | b]: [[1, 2 | 3], [0, 0 | 1]]
  • Second row: 0 = 1 is impossible
  • b ∉ C(A). No solution exists.

Practice Problems

Problem Set 8

Problem 1: Solve $A\mathbf{x} = \mathbf{b}$ completely for:

$$A = [[1, 1, 1], [1, 2, 3]] b = [6, 14]^T$$

Hint: Check consistency, then find particular and nullspace parts.

Solution

RREF: [[1, 0, -1 | -2], [0, 1, 2 | 8]]

Particular: x = [-2, 8, 0]^T (setting free x3=0)

Special: [1, -2, 1]^T

Complete: x = [-2, 8, 0]^T + c*[1, -2, 1]^T

Problem 2: For which values of b1, b2 does $A\mathbf{x} = \mathbf{b}$ have a solution?

$$A = [[1, 3], [2, 6]] b = [b1, b2]^T$$

Hint: The column space is a line. What condition st b satisfy?

Solution

C(A) = span{[1, 2]^T}. So b2 = 2*b1 is required. If b2 ≈  2*b1, no solution.

Problem 3: If x_p1 and x_p2 are two particular solutions to $A\mathbf{x} = \mathbf{b}$, show that their difference is in N(A).

Hint: Subtract the two equations Ax_p1 = b and Ax_p2 = b.

Solution $$A(x_p1 - x_p2) = Ax_p1 - Ax_p2 = b - b = 0 So x_p1 - x_p2 ∈ N(A).$$

Problem 4: Write the complete solution to Ax = 0 and $A\mathbf{x} = \mathbf{b}$ when A is invertible.

Hint: If A is invertible, what does RREF look like?

Solution

If A is invertible, Ax = 0 has only x = 0. For $A\mathbf{x} = \mathbf{b}$, the unique solution is x = A^-1 b. There are no free variables, so nullspace is {0} and the particular solution is unique.
