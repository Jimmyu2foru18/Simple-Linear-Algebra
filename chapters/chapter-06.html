Detailed Topic Breakdowns

The Column Space C(A)

The column space of A, denoted C(A), is the set of all linear combinations of the columns of A. It is a subspace of $\mathbb{R}^m$ (where A is m x n). The system $A\mathbf{x} = \mathbf{b}$ is solvable if and only if b lies in C(A).

The Nullspace N(A)

The nullspace of A, denoted N(A), is the set of all solutions to Ax = 0. It is a subspace of $\mathbb{R}^n$. If A is square and invertible, the nullspace contains only the zero vector. Otherwise, the nullspace has nontrivial solutions.

Rank and Pivot Columns

The rank of A is the dimension of the column space, equal to the number of pivot columns in the row-echelon form of A. The pivot columns of A form a basis for C(A).

Free Variables and the Nullspace

Variables corresponding to non-pivot columns are free variables. Setting one free variable to 1 (and others to 0) generates a special solution. All special solutions span the nullspace.

Computation Examples

Derivation: When is $A\mathbf{x} = \mathbf{b}$ Solvable?

$A\mathbf{x} = \mathbf{b}$ has a solution if and only if b is a linear combination of the columns of A. This means b must be orthogonal to every vector in the left nullspace of A (every row of the reduced matrix [A | b] must have the same rank as A).

$$\text{Condition: } rank([A | b]) = rank(A)$$

Derivation: Rank-Nullity Theorem (Preview)

For an m x n matrix A with rank r:

$$dim(C(A)) = r (number of pivot columns) $$dim(N(A)) = n - r (number of free variables) dim(C(A)) + dim(N(A)) = n (Rank-Nullity Theorem)$$

This fundamental relationship connects the column space and nullspace dimensions.

Learning Strategies

Mnemonic Devices

Mnemonic: "C is for Column, N is for Null"

The column space C(A) answers: "What outputs can A produce?" The nullspace N(A) answers: "What inputs produce zero?" These are the two fundamental questions of linear algebra.

Mnemonic: "Pivot = Basic, Free = Special"

Pivot columns correspond to basic variables (determined by the system). Non-pivot columns correspond to free variables (parameters for special solutions in the nullspace).

Study Tips

  • Always find the RREF to identify pivot columns and free variables
  • Pivot columns of A (not RREF) form a basis for C(A)
  • Special solutions are found by setting one free variable to 1 at a time
  • The nullspace always contains the zero vector
  • Practice switching between matrix notation and span notation

Visual Aids

Figure: Column Space in R^3

For A = [[1, 2, 3], [4, 5, 6], [7, 8, 9]], the column space is a plane through the origin in R^3 because column 3 = -column 1 + 2·column 2 (linearly dependent).

$$c1 = [1] c2 = [2] c3 = [3] = -1\cdot c1 + 2\cdot c2$$ [4] [5] [6] = (-1)[4] + 2[5] [7] [8] [9] = (-1)[7] + 2[8]

Basis for C(A): {c1, c2}. Dimension = 2.

Figure: Nullspace as Solutions to Ax = 0

The nullspace is the set of all x that A "collapses" to zero. For a 3x3 matrix of rank 2, the nullspace is a line through the origin in R^3.

$$Special solutions span N(A): $$For free variable x3: x = [-1, 2, 1]^T N(A) = { c*[-1, 2, 1]^T : c ∈ R }$$

Worked Examples

Example 1: Finding Column Space

Problem: Find a basis and dimension for C(A) where:

$$A = [1 2 3 4]$$ [2 4 6 8] [1 0 1 0]

Solution:

  1. RREF of A: [[1, 0, 1, 0], [0, 1, 1, 2], [0, 0, 0, 0]]
  2. Pivot columns: 1 and 2
  3. Basis for C(A): columns 1 and 2 of A: {[1, 2, 1]^T, [2, 4, 0]^T}
  4. dim(C(A)) = $\text{rank}(A)$ = 2

Example 2: Finding the Nullspace

Problem: Describe the nullspace of A from Example 1.

Solution:

  1. RREF: x1 + x3 = 0, x2 + x3 + 2*x4 = 0
  2. Free variables: x3, x4
  3. Special solution 1 (x3 = 1, x4 = 0): [-1, -1, 1, 0]^T
  4. Special solution 2 (x3 = 0, x4 = 1): [0, -2, 0, 1]^T
  5. Basis for N(A): {[-1, -1, 1, 0]^T, [0, -2, 0, 1]^T}
  6. dim(N(A)) = 2

Practice Problems

Problem Set 6

Problem 1: For A = [[1, 3, 2], [2, 6, 4]], determine whether b = [1, 2]^T is in C(A).

Hint: Solve $A\mathbf{x} = \mathbf{b}$ or check if b is a combination of columns.

Solution

Columns 2 and 3 are ltiples of column 1. C(A) is the line through [1, 2]^T. Since b = [1, 2]^T is exactly column 1, yes, b ∈ C(A).

Problem 2: Find a basis for the nullspace of A = [[1, 2, 3], [1, 2, 3], [2, 4, 6]].

Hint: RREF reveals the free variables.

Solution

RREF: [[1, 2, 3], [0, 0, 0], [0, 0, 0]]

One free variable: x2, x3 are free. Actually, rank = 1, so 2 free variables.

Special solutions: [-2, 1, 0]^T and [-3, 0, 1]^T

Problem 3: Explain why the column space of A^T is the row space of A.

Hint: Think about what the columns of A^T are.

Solution

The columns of A^T are the rows of A. So C(A^T) = span(rows of A) = row space of A.

Problem 4: Can a 3x4 matrix have its column space equal to R^3? Explain.

Hint: How many pivot columns are needed to span R^3?

Solution

Yes. If rank = 3, the three pivot columns span R^3. A 3x4 matrix can have rank 3 (if columns 1, 2, 3 are independent).
