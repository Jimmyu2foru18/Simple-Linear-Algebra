Detailed Topic Breakdowns

The LU Factorization

When we perform Gaussian elimination without row exchanges, the process naturally produces a factorization A = LU, where L is a lower triangular matrix containing the multipliers used during elimination, and U is the resulting upper triangular matrix.

The L Matrix

L is lower triangular with ones on the diagonal. Its subdiagonal entries l_ij are exactly the multipliers used to eliminate the entries below the pivots during Gaussian elimination. L captures the row operations in compact form.

Computational Cost

The cost of Gaussian elimination for an n x n matrix is approximately n^3/3 operations. This is far more efficient than computing A^-1 (which costs n^3 operations) and then ltiplying by b.

Pertation Matrices

When row exchanges are needed, we introduce pertation matrices P. The factorization becomes PA = LU, where P reorders the rows of A to enable safe elimination. P is orthogonal: P^-1 = P^T.

Mathematical Rigor

Derivation: Constructing L from Multipliers

For a 3x3 system, suppose the multipliers are l_21, l_31, l_32. The elimination matrices ltiply as:

$$E_32 * E_31 * E_21 * A = U $$Therefore: A = (E_21)^-1 * (E_31)^-1 * (E_32)^-1 * U = L * U$$

Where L = (E_21)^-1 * (E_31)^-1 * (E_32)^-1 is lower triangular with the multipliers in the appropriate positions.

Derivation: Solving $A\mathbf{x} = \mathbf{b}$ via LU

Once A = LU, solving $A\mathbf{x} = \mathbf{b}$ becomes a two-step process:

$$Step 1: Forward substitution Ly = b (solve for y) $$Step 2: Back substitution Ux = y (solve for x)$$

Forward substitution is efficient because L is lower triangular. Each step requires only one division and a few subtractions.

Learning Strategies

Mnemonic Devices

Mnemonic: "L Stores the Lifts"

L contains the multipliers that "lift" the lower entries to zero during elimination. The entry l_ij tells you how ch of row i to subtract from row j.

Mnemonic: "Forward then Back"

LU decomposition splits one solve into two easy solves: first go down through L (forward), then up through U (backward). Each is triangular and fast.

Study Tips

  • Practice computing L by hand for small 3x3 matrices
  • Verify LU = A after computing both factors
  • Understand that row exchanges require P: PA = LU
  • Note that computing A^-1 costs ~3 $\times$ more than solving $A\mathbf{x} = \mathbf{b}$ ltiple $\times$
  • Recognize when a matrix cannot be factored without pertations

Worked Examples

Example 1: 2x2 LU Factorization

Problem: Factor A = [[2, 1], [4, -6]] into LU.

Solution:

  1. Pivot: a_11 = 2
  2. Multiplier: l_21 = 4/2 = 2
  3. Eliminate: R2 - 2*R1 = [0, -6-2] = [0, -8]
  4. U = [[2, 1], [0, -8]]
  5. L = [[1, 0], [2, 1]]
  6. Verify: LU = [[2, 1], [4, -6]] = A âœ“

Example 2: 3x3 LU Factorization

Problem: Factor A = [[2, -1, 0], [1, 2, 1], [0, 1, 3]].

Solution:

  1. Pivot a_11 = 2, multiplier l_21 = 1/2 = 0.5
  2. R2 - 0.5*R1 = [0, 2.5, 1]
  3. U = [[2, -1, 0], [0, 2.5, 1], [0, 1, 3]]
  4. Next pivot u_22 = 2.5, multiplier l_32 = 1/2.5 = 0.4
  5. R3 - 0.4*R2 = [0, 0, 2.6]
  6. Final U = [[2, -1, 0], [0, 2.5, 1], [0, 0, 2.6]]
  7. L = [[1, 0, 0], [0.5, 1, 0], [0, 0.4, 1]]

Example 3: Solving $A\mathbf{x} = \mathbf{b}$ via LU

Problem: Use the LU factors from Example 1 to solve Ax = [1, 5]^T.

Solution:

  1. Forward solve Ly = b: $y_1 = 1$, $2 \cdot 1 + y_2 = 5 \to y_2 = 3$
  2. Back solve Ux = y: $-8x_2 = 3 \to x_2 = -3/8$
  3. $2x_1 + (-3/8) = 1 \to x_1 = 11/16$

Practice Problems

Problem Set 4

Problem 1: Factor A = [[1, 3], [2, 7]] into LU.

Hint: Find the multiplier for eliminating the (2,1) entry.

Solution

l_21 = 2/1 = 2

U = [[1, 3], [0, 1]]

L = [[1, 0], [2, 1]]

Problem 2: For A = [[1, 1, 0], [2, 3, 1], [1, 2, 1]], find the LU factorization.

Hint: Two pivots needed; track both multipliers.

Solution

l_21 = 2, l_31 = 1

After first column elimination: [[1, 1, 0], [0, 1, 1], [0, 1, 1]]

l_32 = 1

U = [[1, 1, 0], [0, 1, 1], [0, 0, 0]]

L = [[1, 0, 0], [2, 1, 0], [1, 1, 1]]

Problem 3: Show that if A is singular, the LU factorization (without pertations) fails.

Hint: What happens when a pivot is zero?

Solution

If A is singular, elimination produces a zero pivot. Without row exchange, we cannot proceed. A pertation matrix P reorders rows: PA = LU.

Problem 4: Compute the number of multiplications needed to factor an n x n matrix into LU (no pertations).

Hint: Count operations in the elimination loop.

Solution

Approximately n^3/3 multiplications/divisions and a similar number of additions/subtractions. Total ~2n^3/3 flops.
