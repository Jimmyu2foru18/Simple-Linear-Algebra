Detailed Topic Breakdowns

Reduced Row Echelon Form (RREF)

The RREF of a matrix is the simplest equivalent matrix obtained by complete elimination. In RREF, every pivot is 1, each pivot is the only nonzero entry in its column, and pivots appear to the right as we move down rows.

Pivot Variables vs. Free Variables

Pivot variables correspond to pivot columns and are determined by the system. Free variables correspond to non-pivot columns and can be assigned arbitrary values. The number of free variables equals the dimension of the nullspace.

Special Solutions

To find a basis for the nullspace, set each free variable to 1 (one at a time, others to 0) and solve for the pivot variables. Each choice produces one special solution. All special solutions span the nullspace.

RREF and the Identity Matrix

If A is invertible, RREF(A) = I. If A is singular, RREF(A) has at least one zero row. The RREF reveals the rank, pivot positions, and structure of the solution space.

Mathematical Rigor

Derivation: Finding Special Solutions from RREF

Given RREF R with r pivots and n-r free variables:

$$For free variable x_j = 1: $$- Set all other free variables to 0 - Read pivot values from R - One special solution: x has 1 in position j, -R_ij in each pivot row i's column j$$$$

Repeat for each free variable to get the basis of N(A).

Derivation: Nullspace Dimension Forla

From the RREF of an m x n matrix A with rank r:

$$Number of free variables = n - r Each free variable gives one special solution $$Therefore: dim(N(A)) = n - r$$$$

This is half of the Rank-Nullity theorem: $\text{rank}(A)$ + nullity(A) = n.

Learning Strategies

Mnemonic Devices

Mnemonic: "RREF: Reduce to Respectable Form"

RREF means: (1) pivot = 1, (2) zeros above and below each pivot, (3) pivots move right as you go down, (4) zero rows at bottom. This is the "cleanest" form of a matrix.

Mnemonic: "Free to Choose, Pivot to Obey"

Free variables you can assign any value. Pivot variables st obey the equations and take whatever values are forced upon them.

Study Tips

  • Practice computing RREF by hand for 3x3 and 3x4 matrices
  • When finding special solutions, always set ONE free variable to 1 at a time
  • Verify special solutions by ltiplying A * x_special and confirming it equals zero
  • The nullspace contains the zero vector and is closed under addition and scalar multiplication
  • If no free variables exist, nullspace = {0} only

Worked Examples

Example 1: Solving Ax = 0

Problem: Describe the nullspace of A = [[1, 2, 2, 2], [2, 4, 6, 8], [3, 6, 8, 10]].

Solution:

  1. RREF: [[1, 2, 0, -2], [0, 0, 1, 2], [0, 0, 0, 0]]
  2. Pivot columns: 1, 3. Free variables: x2, x4
  3. Special solution 1 (x2=1, x4=0): [-2, 1, 0, 0]^T
  4. Special solution 2 (x2=0, x4=1): [2, 0, -2, 1]^T
  5. N(A) = c1*[-2, 1, 0, 0]^T + c2*[2, 0, -2, 1]^T

Example 2: Square Invertible Matrix

Problem: What is the nullspace of A = [[1, 2], [3, 8]]?

Solution:

  • RREF: [[1, 0], [0, 1]] (identity)
  • Two pivots, zero free variables
  • Only solution to Ax = 0 is x = [0, 0]^T
  • N(A) = {0}, dim(N(A)) = 0

Practice Problems

Problem Set 7

Problem 1: Find the RREF and describe the nullspace of A = [[1, 1, 1], [1, 2, 3], [2, 3, 4]].

Hint: Notice any relationships between rows or columns.

Solution

RREF: [[1, 0, -1], [0, 1, 2], [0, 0, 0]]

Free variable: x3

Special solution: [1, -2, 1]^T

N(A) = c*[1, -2, 1]^T

Problem 2: For A = [[1, 2, 3, 4], [2, 4, 6, 8]], how many independent special solutions exist?

Hint: Find the rank first.

Solution

Rank = 1 (row 2 = 2*row 1). Free variables = 4 - 1 = 3. Three special solutions span N(A).

Problem 3: Construct a 3x3 matrix whose nullspace is a line (dimension 1).

Hint: Rank should be 2.

Solution $$A = [[1, 0, -1],$$ [0, 1, -1], [0, 0, 0]] $$N(A) = c*[1, 1, 1]^T$$

Problem 4: If A is 5x7 and $\text{rank}(A)$ = 3, what is dim(N(A))?

Hint: Use the Rank-Nullity theorem.

Solution

dim(N(A)) = n - rank = 7 - 3 = 4.
