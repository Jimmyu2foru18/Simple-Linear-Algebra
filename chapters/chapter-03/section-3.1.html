Section 3.1: Vector Spaces and Subspaces

Assigned problems: 3, 5, 12, 15, 18, 19, 25. Source: linearAlgebraSolutionsComplete.pdf (PDF Chapter 4, Section 4.1).

What is this section about?

What is a vector space? A vector space is a set of vectors closed under addition and scalar multiplication. A subspace is a subset of a vector space that is itself a vector space under the same operations.

Concept Overview

A subspace of $\mathbb{R}^n$ is a set $H$ that satisfies three properties:

  • The zero vector is in $H$.
  • For each $\mathbf{u}, \mathbf{v}$ in $H$, the sum $\mathbf{u} + \mathbf{v}$ is in $H$ (closed under addition).
  • For each $\mathbf{u}$ in $H$ and scalar $c$, the vector $c\mathbf{u}$ is in $H$ (closed under scalar multiplication).

By Theorem 1, if $H = \text{Span}\{\mathbf{v}_1, \dots, \mathbf{v}_p\}$, then $H$ is a subspace of $\mathbb{R}^n$.

Problem 3

Problem: Determine whether the given set $H$ is a subspace of $\mathbb{R}^2$.

Solution

Example: If $\mathbf{u} = \begin{bmatrix} 0.5 \\ 0.5 \end{bmatrix}$ and $c = 4$, then $\mathbf{u}$ is in $H$ but $c\mathbf{u}$ is not in $H$. Since $H$ is not closed under scalar multiplication, $H$ is not a subspace of $\mathbb{R}^2$.

Problem 5

Problem: Determine whether the given set is a subspace.

Solution

Yes. Since the set is $\text{Span}\{\mathbf{v}\}$, the set is a subspace by Theorem 1.

The set is a subspace.

Problem 12

Problem: Determine whether $W = \text{Span}\{\mathbf{u}, \mathbf{v}\}$ is a subspace of $\mathbb{R}^4$.

Solution

The set $W = \text{Span}\{\mathbf{u}, \mathbf{v}\}$ where $\mathbf{u} = \begin{bmatrix} 1 \\ 1 \\ 2 \\ 0 \end{bmatrix}$ and $\mathbf{v} = \begin{bmatrix} 3 \\ 1 \\ 4 \\ 4 \end{bmatrix}$. Thus $W$ is a subspace of $\mathbb{R}^4$ by Theorem 1.

$W$ is a subspace of $\mathbb{R}^4$.

Problem 15

Problem: Determine whether $W$ is a vector space.

Solution

Since the zero vector is not in $W$, $W$ is not a vector space.

Problem 18

Problem: Find a spanning set for $W$.

Solution

Since a vector $\mathbf{w}$ in $W$ may be written as:

$$\mathbf{w} = a\begin{bmatrix} 4 \\ 0 \\ 1 \\ 2 \end{bmatrix} + b\begin{bmatrix} 3 \\ 0 \\ 0 \\ 0 \end{bmatrix} + c\begin{bmatrix} 0 \\ 1 \\ 1 \\ 1 \end{bmatrix}$$

A spanning set is $\left\{\begin{bmatrix} 4 \\ 0 \\ 1 \\ 2 \end{bmatrix}, \begin{bmatrix} 3 \\ 0 \\ 0 \\ 0 \end{bmatrix}, \begin{bmatrix} 0 \\ 1 \\ 1 \\ 1 \end{bmatrix}\right\}$.

Problem 19

Problem: Let $H$ be the set of all functions described by $y(t) = c_1\cos\omega t + c_2\sin\omega t$. Show $H$ is a subspace.

Solution

Then $H$ is a subset of the vector space $V$ of all real-valued functions, and may be written as $H = \text{Span}\{\cos\omega t, \sin\omega t\}$. By Theorem 1, $H$ is a subspace of $V$ and is hence a vector space.
