Section 3.3: Linearly Independent Sets; Bases

What is this section about?

What is a basis? A basis for a subspace is a linearly independent set of vectors that spans the subspace. Every subspace has a basis, and all bases for a given subspace have the same number of vectors.

Core Lecture, Gilbert Strang (MIT)

Concept Overview

A set of vectors $\{\mathbf{v}_1, \dots, \mathbf{v}_p\}$ in $\mathbb{R}^n$ is linearly independent if the vector equation $x_1\mathbf{v}_1 + \cdots + x_p\mathbf{v}_p = \mathbf{0}$ has only the trivial solution.

A basis for a subspace $H$ is a linearly independent set in $H$ that spans $H$.

The pivot columns of $A$ form a basis for $\text{Col } A$.

Worked Problems from linearAlgebraSolutionsComplete.pdf

Problem 1

Problem: Determine whether the given set of vectors is a basis for $\mathbb{R}^3$.

Solution

Consider the matrix whose columns are the given set of vectors. This $3 \times 3$ matrix is in echelon form and has 3 pivot positions. Thus by the Invertible Matrix Theorem, its columns are linearly independent and span $\mathbb{R}^3$.

The given set of vectors is a basis for $\mathbb{R}^3$.

Problem 3

Problem: Determine whether the given set of vectors is a basis for $\mathbb{R}^3$.

Solution

Consider the matrix whose columns are the given set of vectors. The reduced echelon form has only two pivot positions.

Thus its columns do not form a basis for $\mathbb{R}^3$; the set is neither linearly independent nor does it span $\mathbb{R}^3$.

Problem 7

Problem: Determine whether the given set of vectors is a basis for $\mathbb{R}^3$.

Solution

Consider the matrix whose columns are the given set of vectors. Since the matrix cannot have a pivot in each row, its columns cannot span $\mathbb{R}^3$; thus the given set of vectors is not a basis for $\mathbb{R}^3$. The reduced echelon form has a pivot in each column.

The given set of vectors is linearly independent but does not span $\mathbb{R}^3$.

Problem 11

Problem: Find a basis for $\text{Nul } A$ where $A = \begin{bmatrix} 1 & 2 & 1 \end{bmatrix}$.

Solution

The general solution is $x = -2y - z$ with $y$ and $z$ free.

$$\mathbf{x} = y\begin{bmatrix} -2 \\ 1 \\ 0 \end{bmatrix} + z\begin{bmatrix} -1 \\ 0 \\ 1 \end{bmatrix}$$

A basis for $\text{Nul } A$ is $\left\{\begin{bmatrix} -2 \\ 1 \\ 0 \end{bmatrix}, \begin{bmatrix} -1 \\ 0 \\ 1 \end{bmatrix}\right\}$.

Problem 15

Problem: Find a basis for the space spanned by the given vectors.

Solution

Since the reduced echelon form shows that the first, second, and fourth columns are pivot columns, a basis for the space spanned by the given vectors is:

$$\left\{\begin{bmatrix} 1 \\ 0 \\ 1 \end{bmatrix}, \begin{bmatrix} 0 \\ 1 \\ 3 \end{bmatrix}, \begin{bmatrix} 2 \\ 3 \\ 7 \end{bmatrix}\right\}$$

A basis for the space is $\left\{\begin{bmatrix} 1 \\ 0 \\ 1 \end{bmatrix}, \begin{bmatrix} 0 \\ 1 \\ 3 \end{bmatrix}, \begin{bmatrix} 2 \\ 3 \\ 7 \end{bmatrix}\right\}$.

Problem 27

Problem: Show that $\{\cos\omega t, \sin\omega t\}$ is a basis for the subspace.

Solution

The set $\{\cos\omega t, \sin\omega t\}$ spans the subspace. By inspection, we note that this set is linearly independent.

So $\{\cos\omega t, \sin\omega t\}$ is a basis for the subspace.
