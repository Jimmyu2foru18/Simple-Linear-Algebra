Detailed Topic Breakdowns

The Error Vector

The error vector is the component of a vector $\mathbf{b}$ that is perpendicular to a given vector $\mathbf{a}$. Starting with the original vector $\mathbf{b}$, we remove its projection onto $\mathbf{a}$ to obtain the perpendicular part.

Formula for the Error Vector

If $\mathbf{b}$ is the original vector and $\mathbf{a}$ is the vector we project onto, the error vector $\mathbf{e}$ (or $\mathbf{B}$ in the lecture notation) is:

$$ \mathbf{B} = \mathbf{b} - \frac{\mathbf{a}^T\mathbf{b}}{\mathbf{a}^T\mathbf{a}}\mathbf{a} $$

To verify orthogonality, we check that $\mathbf{a}^T\mathbf{B} = 0$. Expanding:

$$ \mathbf{a}^T\mathbf{B} = \mathbf{a}^T\mathbf{b} - \frac{\mathbf{a}^T\mathbf{b}}{\mathbf{a}^T\mathbf{a}}\mathbf{a}^T\mathbf{a} = \mathbf{a}^T\mathbf{b} - \mathbf{a}^T\mathbf{b} = 0 $$

Gram-Schmidt Orthogonalization

Given independent vectors $\mathbf{a}$, $\mathbf{b}$, and $\mathbf{c}$, Gram-Schmidt produces orthogonal vectors $\mathbf{A}$, $\mathbf{B}$, and $\mathbf{C}$:

  • $\mathbf{A} = \mathbf{a}$ (unchanged)
  • $\mathbf{B} = \mathbf{b} - \frac{\mathbf{a}^T\mathbf{b}}{\mathbf{a}^T\mathbf{a}}\mathbf{a}$
  • $\mathbf{C} = \mathbf{c} - \frac{\mathbf{a}^T\mathbf{c}}{\mathbf{a}^T\mathbf{a}}\mathbf{a} - \frac{\mathbf{b}^T\mathbf{c}}{\mathbf{b}^T\mathbf{b}}\mathbf{b}$

To obtain orthonormal vectors, divide each by its length: $\mathbf{q}_1 = \frac{\mathbf{A}}{\|\mathbf{A}\|}$, $\mathbf{q}_2 = \frac{\mathbf{B}}{\|\mathbf{B}\|}$, etc.

Worked Numerical Example

Example: Gram-Schmidt with Two Vectors

Given:

  • $\mathbf{a} = \begin{bmatrix} 1 \\ 1 \\ 1 \end{bmatrix}$
  • $\mathbf{b} = \begin{bmatrix} 1 \\ 0 \\ 2 \end{bmatrix}$

Step 1: Compute $\mathbf{B}$:

$\mathbf{a}^T\mathbf{b} = 1(1) + 1(0) + 1(2) = 3$

$\mathbf{a}^T\mathbf{a} = 1^2 + 1^2 + 1^2 = 3$

$$ \mathbf{B} = \begin{bmatrix} 1 \\ 0 \\ 2 \end{bmatrix} - \frac{3}{3}\begin{bmatrix} 1 \\ 1 \\ 1 \end{bmatrix} = \begin{bmatrix} 1-1 \\ 0-1 \\ 2-1 \end{bmatrix} = \begin{bmatrix} 0 \\ -1 \\ 1 \end{bmatrix} $$

Step 2: Verify orthogonality:

$\mathbf{a}^T\mathbf{B} = 1(0) + 1(-1) + 1(1) = 0$ âœ“

Step 3: Normalize to get orthonormal basis:

$\mathbf{q}_1 = \frac{1}{\sqrt{3}}\begin{bmatrix} 1 \\ 1 \\ 1 \end{bmatrix}$, $\mathbf{q}_2 = \frac{1}{\sqrt{2}}\begin{bmatrix} 0 \\ -1 \\ 1 \end{bmatrix}$

Step 4: Form the matrix $Q$:

$$ Q = \begin{bmatrix} \frac{1}{\sqrt{3}} & 0 \\ \frac{1}{\sqrt{3}} & -\frac{1}{\sqrt{2}} \\ \frac{1}{\sqrt{3}} & \frac{1}{\sqrt{2}} \end{bmatrix} $$

The A = QR Factorization

The connection between the original matrix $A$ and the orthonormal matrix $Q$ is expressed through an upper triangular matrix $R$:

$$ A = QR $$

Since $Q$ has orthonormal columns and $A$ has the same column space, $R$ must be upper triangular. The entries of $R$ are inner products of the original columns of $A$ with the orthonormal columns of $Q$. The zero entries in $R$ arise because each $\mathbf{q}_i$ is constructed to be perpendicular to all previous $\mathbf{q}_j$ ($j < i$).

Computation Examples

Formal Definitions

Orthogonal vectors: Vectors $\mathbf{u}$ and $\mathbf{v}$ are orthogonal if $\mathbf{u}^T\mathbf{v} = 0$.

Orthonormal vectors: Vectors are orthonormal if they are orthogonal and each has unit length ($\|\mathbf{v}\| = 1$).

Gram-Schmidt process: A method for converting a set of linearly independent vectors into an orthonormal set spanning the same subspace.

QR factorization: Any matrix $A$ with linearly independent columns can be factored as $A = QR$ where $Q$ has orthonormal columns and $R$ is upper triangular.

Learning Strategies

Mnemonic Devices

Mnemonic: "Orthogonal: Perpendicular, Orthonormal: Perpendicular Unit Length"

Orthogonal vectors have dot product zero. Orthonormal vectors have dot product zero AND length one. The extra "n" in orthonormal stands for "normalized" (unit length).

Mnemonic: "Gram-Schmidt: Subtract Projections One by One"

Start with the first vector unchanged. For each subsequent vector, subtract its projection onto all previous orthogonal vectors. The result is orthogonal to everything before it. Then normalize.

Mnemonic: "QR: Q is Orthonormal, R is Upper Triangular"

In A = QR, Q has orthonormal columns (Q^T Q = I) and R is upper triangular. The entries of R are inner products: R_ij = q_i^T a_j. Because q_i is perpendicular to q_j for j < i, the lower triangle of R is zero.

Visual Aids

Figure: Gram-Schmidt as Successive Projection Removal

Starting with independent vectors $\mathbf{a}, \mathbf{b}, \mathbf{c}$, Gram-Schmidt subtracts projections step by step:

$$\mathbf{A} = \mathbf{a}$$

$$\mathbf{B} = \mathbf{b} - \frac{\mathbf{a}^T\mathbf{b}}{\mathbf{a}^T\mathbf{a}}\mathbf{a} \quad (\text{remove projection of } \mathbf{b} \text{ onto } \mathbf{A})$$

$$\mathbf{C} = \mathbf{c} - \frac{\mathbf{a}^T\mathbf{c}}{\mathbf{a}^T\mathbf{a}}\mathbf{a} - \frac{\mathbf{b}^T\mathbf{c}}{\mathbf{b}^T\mathbf{b}}\mathbf{b} \quad (\text{remove projections of } \mathbf{c} \text{ onto } \mathbf{A} \text{ and } \mathbf{B})$$

Each new vector is orthogonal to all previous ones.

Figure: The QR Factorization Geometry

The matrix $A$ has columns $\mathbf{a}_1, \mathbf{a}_2, \ldots, \mathbf{a}_n$. The matrix $Q$ has orthonormal columns $\mathbf{q}_1, \mathbf{q}_2, \ldots, \mathbf{q}_n$ spanning the same column space. The upper triangular matrix $R$ encodes the coefficients:

$$A = QR \implies \mathbf{a}_j = \sum_{i=1}^{j} r_{ij} \mathbf{q}_i$$

Because each $\mathbf{q}_j$ is orthogonal to all $\mathbf{q}_i$ with $i < j$, the coefficients $r_{ij}$ for $i > j$ are zero.

Figure: Orthogonal Matrix as Rotation/Reflection

An orthogonal matrix $Q$ with $\det(Q) = +1$ is a rotation. An orthogonal matrix with $\det(Q) = -1$ is a reflection. Both preserve lengths and angles: $|Q\mathbf{x}| = |\mathbf{x}|$ for all $\mathbf{x}$.

$$Q^T Q = I \implies |Q\mathbf{x}|^2 = \mathbf{x}^T Q^T Q \mathbf{x} = \mathbf{x}^T \mathbf{x} = |\mathbf{x}|^2$$

Worked Examples

Example 1: Basic Application

Problem: Apply Gram-Schmidt to vectors $\mathbf{a} = [1, 1, 1]^T$ and $\mathbf{b} = [1, 0, 2]^T$.

Solution: See the worked numerical example above. The resulting orthonormal basis is $\mathbf{q}_1 = \frac{1}{\sqrt{3}}[1,1,1]^T$ and $\mathbf{q}_2 = \frac{1}{\sqrt{2}}[0,-1,1]^T$.

Example 2: Advanced Application

Problem: Show that $A = QR$ for the example above, and identify $R$.

Solution:

  1. $R = Q^T A$ (since $Q$ has orthonormal columns)
  2. $R_{11} = \mathbf{q}_1^T \mathbf{a} = \sqrt{3}$, $R_{12} = \mathbf{q}_1^T \mathbf{b} = \sqrt{3}$
  3. $R_{22} = \mathbf{q}_2^T \mathbf{b} = \sqrt{2}$
  4. $$ R = \begin{bmatrix} \sqrt{3} & \sqrt{3} \\ 0 & \sqrt{2} \end{bmatrix} $$

Practice Problems

Problem Set 17

Problem 1: Apply Gram-Schmidt to $\mathbf{a} = [1, 2]^T$ and $\mathbf{b} = [2, 1]^T$ to find orthonormal $\mathbf{q}_1, \mathbf{q}_2$.

Hint: Compute projections and normalize.

Solution

$\mathbf{q}_1 = \frac{1}{\sqrt{5}}[1,2]^T$, $\mathbf{q}_2 = \frac{1}{\sqrt{5}}[2,-1]^T$

Problem 2: Given three independent vectors in $\mathbb{R}^3$, write the full Gram-Schmidt formula for the third orthogonal vector $\mathbf{C}$.

Hint: Subtract projections onto both $\mathbf{A}$ and $\mathbf{B}$.

Solution

$\mathbf{C} = \mathbf{c} - \frac{\mathbf{a}^T\mathbf{c}}{\mathbf{a}^T\mathbf{a}}\mathbf{a} - \frac{\mathbf{b}^T\mathbf{c}}{\mathbf{b}^T\mathbf{b}}\mathbf{B}$

Problem 3: Prove that if $A$ has independent columns, then $R$ in the QR factorization $A = QR$ is invertible.

Hint: Use the fact that $Q$ has orthonormal columns and $Q^T Q = I$.

Solution

Since $A = QR$ and $A$ has independent columns, $A$ is invertible. Also $Q^T Q = I$, so $R = Q^T A$ is a product of invertible matrices, hence invertible.
