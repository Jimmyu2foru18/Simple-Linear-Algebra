Chapter 22: Diagonalization and Powers of A

Computing matrix powers through diagonalization. This chapter reveals how any diagonalizable matrix can be written as A = SΛS-1, which immediately gives Ak = SΛkS-1. The Fibonacci sequence serves as the central example, showing how eigenvalues control the growth rate of dynamical systems and how a second-order recurrence can be converted to a first-order matrix system.

Detailed Topic Breakdowns

The Diagonalization Formula

If A is diagonalizable with eigenvector matrix S and eigenvalue matrix Λ, then A = SΛS-1. Consequently, Ak = SΛkS-1. This formula means that to compute Ak, you expand the initial vector u0 into eigenvectors, multiply each eigencomponent by its eigenvalue raised to the k-th power, and recombine. The matrix S contains the eigenvectors as columns, and Λ is the diagonal matrix of eigenvalues.

From Recurrence to Dynamical Systems

The Fibonacci sequence satisfies Fk+2 = Fk+1 + Fk, which is a second-order scalar recurrence. To convert it to a first-order system, define the state vector uk = [Fk+1, Fk]T. Then uk+1 = Auk where A = [[1, 1], [1, 0]]. This transforms a single second-order equation into a 2×2 matrix system. The matrix A captures the recurrence in first-order form.

Eigenvalues of the Fibonacci Matrix

For A = [[1, 1], [1, 0]], the characteristic equation is det(A - λI) = λ2 - λ - 1 = 0. The eigenvalues are λ1 = (1+√5)/2 ≈ 1.618 and λ2 = (1-√5)/2 ≈ -0.618. They add to the trace (1) and multiply to the determinant (-1). The dominant eigenvalue λ1 is the golden ratio, and it controls the exponential growth of the Fibonacci numbers. The second eigenvalue λ2 has magnitude less than 1, so its contribution vanishes as k increases.

Eigenvectors and the Expansion of u0

The eigenvectors of A are x1 = [λ1, 1]T and x2 = [λ2, 1]T. The initial vector u0 = [F1, F0]T = [1, 0]T is expressed as a linear combination u0 = c1x1 + c2x2. Then uk = Aku0 = c1λ1kx1 + c2λ2kx2. As k grows, the term with |λ1|k dominates because |λ1| > 1 and |λ2| < 1.

Dynamic Systems vs Static Problems

Static problems solve Ax = b for a fixed right-hand side. Dynamic problems follow uk+1 = Auk over time. The eigenvalues determine the long-term behavior: if |λ| < 1, solutions decay to zero; if |λ| > 1, solutions grow exponentially; if |λ| = 1, solutions remain bounded. For the Fibonacci matrix, λ1 ≈ 1.618 > 1 means exponential growth, and the growth rate is approximately λ1k.

Mathematical Rigor

Derivation: The Diagonalization Formula for Ak

If A has n independent eigenvectors, they form the columns of S = [x1 x2 ... xn]. Then A = SΛS-1 where Λ = diag(λ1, λ2, ..., λn). Raising to the k-th power:

$$ A^k = (S\Lambda S^{-1})^k = S\Lambda S^{-1} S\Lambda S^{-1} \cdots S\Lambda S^{-1} $$

Since S-1S = I in the middle, all interior terms cancel:

$$ A^k = S\Lambda^k S^{-1} $$

Here Λk = diag(λ1k, λ2k, ..., λnk). This is the fundamental formula for matrix powers.

Derivation: Fibonacci Recurrence as a Matrix System

The scalar recurrence Fk+2 = Fk+1 + Fk with F0 = 0, F1 = 1 is converted to first-order form by defining uk = [Fk+1, Fk]T. Then:

$$ u_{k+1} = \begin{bmatrix} F_{k+2} \\ F_{k+1} \end{bmatrix} = \begin{bmatrix} F_{k+1} + F_k \\ F_{k+1} \end{bmatrix} = \begin{bmatrix} 1 & 1 \\ 1 & 0 \end{bmatrix} \begin{bmatrix} F_{k+1} \\ F_k \end{bmatrix} = Au_k $$

Thus uk = Aku0 with u0 = [1, 0]T. The Fibonacci numbers appear as components of uk: Fk is the second component of uk-1.

Derivation: Eigenvalues and Eigenvectors of the Fibonacci Matrix

For A = [[1, 1], [1, 0]], the characteristic equation is:

$$ \det(A - \lambda I) = \det\begin{pmatrix} 1-\lambda & 1 \\ 1 & -\lambda \end{pmatrix} = \lambda^2 - \lambda - 1 = 0 $$

Using the quadratic formula:

$$ \lambda_{1,2} = \frac{1 \pm \sqrt{5}}{2} $$

For each eigenvalue, the eigenvector satisfies (A - λI)x = 0. For a 2×2 matrix, if λ is an eigenvalue, then [λ, 1]T is an eigenvector because:

$$ \begin{pmatrix} 1-\lambda & 1 \\ 1 & -\lambda \end{pmatrix} \begin{pmatrix} \lambda \\ 1 \end{pmatrix} = \begin{pmatrix} \lambda - \lambda^2 + 1 \\ \lambda - \lambda^2 \end{pmatrix} = \begin{pmatrix} 0 \\ 0 \end{pmatrix} $$

since λ2 - λ - 1 = 0. Thus x1 = [λ1, 1]T and x2 = [λ2, 1]T.

Learning Strategies

Mnemonic Devices

Mnemonic: "A to the k = S Lambda to the k S inverse"

To compute Ak, diagonalize A = SΛS-1, then raise the diagonal matrix Λ to the k-th power entrywise, and sandwich it between S and S-1. The hard work is finding S and Λ; raising Λk is trivial.

Mnemonic: "Second Order to First Order: Stack the State"

To convert a recurrence like Fk+2 = Fk+1 + Fk into a matrix system, define uk = [Fk+1, Fk]T. This stacks the current and previous terms into a vector, turning a scalar recurrence into a first-order system.

Mnemonic: "Dominant Eigenvalue Controls Growth"

For large k, the term with the largest |λ| dominates Ak. If |λ1| > |λ2| > ... > |λn|, then Ak ≈ λ1k times a rank-1 matrix. The Fibonacci growth rate is λ1 ≈ 1.618.

Study Tips

  • Always check that A has n independent eigenvectors before applying Ak = SΛkS-1
  • For a 2×2 matrix, the eigenvectors often have the simple form [λ, 1]T
  • The trace equals the sum of eigenvalues; the determinant equals the product - use these to check your work
  • When converting recurrences to matrix form, the state vector must contain enough history to make the system first-order
  • The dominant eigenvalue (largest magnitude) determines the long-term growth or decay rate
  • If all |λi| < 1, then Ak → 0 as k → ∞

Computing Ak via the diagonalization formula:

$$ A = S\Lambda S^{-1} \implies A^k = S\Lambda^k S^{-1} $$

S contains eigenvectors as columns. Λk raises each eigenvalue to the k-th power on the diagonal. The result is Ak = SΛkS-1.

Figure: Fibonacci Recurrence as a Dynamical System

The Fibonacci recurrence Fk+2 = Fk+1 + Fk becomes the matrix system uk+1 = Auk:

$$ A = \begin{bmatrix} 1 & 1 \\ 1 & 0 \end{bmatrix}, \quad u_k = \begin{bmatrix} F_{k+1} \\ F_k \end{bmatrix} $$

The eigenvalues λ1 ≈ 1.618 and λ2 ≈ -0.618 determine the growth. The dominant eigenvalue λ1 causes exponential growth at rate ≈ 1.618k.

Figure: Eigenvalue Spectrum and Long-Term Behavior

For different dynamical systems, the eigenvalue locations control the behavior:

$$ |\lambda| < 1: \text{decay to zero} \quad |\lambda| > 1: \text{exponential growth} \quad |\lambda| = 1: \text{oscillation or steady state} $$

For the Fibonacci matrix, λ1 ≈ 1.618 lies outside the unit circle (growth), while λ2 ≈ -0.618 lies inside (decay). The long-term behavior is dominated by the larger magnitude.

Worked Examples

Example 1: Diagonalizing a 2×2 Matrix

Problem: Diagonalize A = [[1, 1], [1, 0]] and compute A5 using the formula Ak = SΛkS-1.

Solution:

  • Eigenvalues: λ1 = (1+√5)/2 ≈ 1.618, λ2 = (1-√5)/2 ≈ -0.618
  • Eigenvectors: x1 = [λ1, 1]T, x2 = [λ2, 1]T
  • S = [[λ1, λ2], [1, 1]], Λ = [[λ1, 0], [0, λ2]]
  • A5 = SΛ5S-1. Rather than multiply A five times, compute Λ5 = [[λ15, 0], [0, λ25]] and sandwich between S and S-1
  • This gives F6 = 8 and F5 = 5 in the matrix entries

Example 2: Fibonacci Numbers via Diagonalization

Problem: Use diagonalization to find a closed formula for Fk and explain why F100 ≈ c1λ1100.

Solution:

  • u0 = [1, 0]T = c1x1 + c2x2
  • Solving for c1, c2 gives c1 = 1/√5, c2 = -1/√5
  • Thus uk = (1/√5)λ1kx1 - (1/√5)λ2kx2
  • The second term λ2100 ≈ (-0.618)100 ≈ 10-25 is negligible
  • Therefore F100 ≈ (1/√5)λ1100 ≈ (1/√5)(1.618)100

Example 3: Dynamics of Ak for Different Eigenvalues

Problem: Describe the long-term behavior of uk = Aku0 for matrices with eigenvalues (a) 0.5 and 0.3, (b) 2 and -3, (c) 1 and 1.

Solution:

  • (a) Both |λ| < 1: uk → 0 exponentially fast
  • (b) |λ1| = 2 > 1 and |λ2| = 3 > 1: uk grows exponentially, dominated by (-3)k with sign oscillations
  • (c) |λ| = 1: uk stays bounded but may oscillate; growth rate is polynomial, not exponential

Practice Problems

Problem Set 22

Problem 1: Let A = [[2, 1], [1, 2]]. Diagonalize A and compute A10 using the formula Ak = SΛkS-1.

Hint: Find eigenvalues 3 and 1 with eigenvectors [1,1]T and [1,-1]T. Then S = [[1,1],[1,-1]].

Solution

Λ = [[3,0],[0,1]], Λ10 = [[310,0],[0,1]]. S-1 = (1/2)[[1,1],[1,-1]]. A10 = SΛ10S-1 gives the result without multiplying A ten times.

Problem 2: For the Fibonacci matrix A = [[1, 1], [1, 0]], verify that the eigenvectors are [λ1, 1]T and [λ2, 1]T by direct multiplication.

Hint: Show that (A - λI)[λ, 1]T = 0 using the fact that λ2 - λ - 1 = 0.

Solution

(A - λI)[λ, 1]T = [1-λ, 1; 1, -λ][λ, 1]T = [λ - λ2 + 1, λ - λ2]T. Since λ2 = λ + 1, both entries are zero. Thus [λ, 1]T is indeed an eigenvector.

Problem 3: Convert the recurrence Gk+2 = 2Gk+1 + 3Gk with G0 = 1, G1 = 2 into a first-order matrix system. Find the matrix A and the initial vector u0.

Hint: Define uk = [Gk+1, Gk]T and write uk+1 = Auk.

Solution

uk = [Gk+1, Gk]T. Then uk+1 = [Gk+2, Gk+1]T = [2Gk+1 + 3Gk, Gk+1]T = [[2, 3], [1, 0]]uk. So A = [[2, 3], [1, 0]] and u0 = [2, 1]T.

Problem 4: Explain why Ak → 0 as k → ∞ when all eigenvalues satisfy |λi| < 1. What happens if one eigenvalue has |λ| = 1 and all others have |λ| < 1?

Hint: Consider the diagonal matrix Λk and what happens to each diagonal entry as k grows.

Solution

If |λi| < 1 for all i, then λik → 0 as k → ∞, so Λk → 0. Since Ak = SΛkS-1, we have Ak → 0. If one eigenvalue has |λ| = 1 and others have |λ| < 1, then Ak does not converge to zero; the term with |λ| = 1 persists, and Ak approaches a rank-1 projection onto the corresponding eigenvector direction.
