What is this section about?

What is an isomorphism? Two vector spaces are isomorphic if an invertible linear transformation exists between them. Finite-dimensional spaces are isomorphic exactly when they have the same dimension.

Core Lecture, Gilbert Strang (MIT)

Concept Overview

A linear transformation $T: V \to W$ is an isomorphism if it is both one-to-one and onto.

Two vector spaces $V$ and $W$ are isomorphic if there exists an isomorphism $T: V \to W$.

Key Theorem: Two finite-dimensional vector spaces are isomorphic if and only if they have the same dimension.

The coordinate mapping $[\mathbf{x}]_{\mathcal{B}}$ from $V$ to $\mathbb{R}^n$ relative to a basis $\mathcal{B}$ is an isomorphism.
