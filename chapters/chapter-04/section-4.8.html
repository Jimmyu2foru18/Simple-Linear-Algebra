What is this section about?

What is a difference equation? A difference equation models a discrete dynamical system where each state vector is obtained by applying a linear transformation to the previous state.

Core Lecture, Gilbert Strang (MIT)

Concept Overview

A linear difference equation has the form:

$$\mathbf{x}_{k+1} = A\mathbf{x}_k$$

where $A$ is an $n \times n$ matrix. The solution is:

$$\mathbf{x}_k = A^k\mathbf{x}_0$$

If $A$ is diagonalizable with $A = PDP^{-1}$, then $A^k = PD^kP^{-1}$, which gives an explicit formula for $\mathbf{x}_k$.

Problem 3

Problem: Find the solution to the difference equation.

Solution

The solution to the difference equation is found by diagonalizing $A$ and computing $A^k\mathbf{x}_0$.
