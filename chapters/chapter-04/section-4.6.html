What is this section about?

What is rank? The rank of a matrix is the dimension of its column space, equal to the number of pivot columns in the matrix.

Core Lecture, Gilbert Strang (MIT)

Concept Overview

The rank of a matrix $A$, written $\text{rank } A$, is the dimension of the column space of $A$.

Equivalently, $\text{rank } A$ equals the number of pivot columns in $A$.

Rank Theorem: For an $m \times n$ matrix $A$, $\text{rank } A + \dim(\text{Nul } A) = n$.

Worked Problems from linearAlgebraSolutionsComplete.pdf

Problem 1

Problem: Find the dimension of $\text{Col } A$ and $\text{Nul } A$ for a given matrix.

Solution

This subspace is $\text{Span}\{\mathbf{v}_1, \mathbf{v}_2\}$ where $\mathbf{v}_1 = \begin{bmatrix} 1 \\ 1 \\ 0 \end{bmatrix}$ and $\mathbf{v}_2 = \begin{bmatrix} 4 \\ 3 \\ -1 \end{bmatrix}$. Since $\mathbf{v}_1$ and $\mathbf{v}_2$ are not multiples of each other, $\{\mathbf{v}_1, \mathbf{v}_2\}$ is linearly independent and is thus a basis for $H$. Hence the dimension of $H$ is 2.

Problem 7

Problem: Find the dimension of $H = \text{Nul } A$ where $A$ reduces to the identity matrix.

Solution

Since $A$ row reduces to $\begin{bmatrix} 1 & 0 & 0 \\ 0 & 1 & 0 \\ 0 & 0 & 1 \end{bmatrix}$, the homogeneous system has only the trivial solution. Thus $H = \text{Nul } A = \{\mathbf{0}\}$, and the dimension of $H$ is 0.

Problem 8

Problem: From the equation $a - 3b + c = 0$, find the dimension of the subspace.

Solution

From the equation $a - 3b + c = 0$, it is seen that $(a, b, c, d) = b(3, 1, 0, 0) + c(-1, 0, 1, 0) + d(0, 0, 0, 1)$.

Thus the subspace is $\text{Span}\{\mathbf{v}_1, \mathbf{v}_2, \mathbf{v}_3\}$ where $\mathbf{v}_1 = (3,1,0,0)$, $\mathbf{v}_2 = (-1,0,1,0)$, and $\mathbf{v}_3 = (0,0,0,1)$. It is easily checked that this set of vectors is linearly independent.

Hence the dimension of the subspace is 3.

Problem 11

Problem: Find the dimension of $\text{Col } A$ where $A$ has two pivot columns.

Solution

The matrix $A$ with these vectors as its columns row reduces to show two pivot columns, so the dimension of $\text{Col } A$ (which is the dimension of $H$) is 2.

$\dim(\text{Col } A) = 2$.

Problem 17

Problem: Find the dimension of $\text{Col } A$ and $\text{Nul } A$ where $A$ is in echelon form with three pivot columns and no columns without pivots.

Solution

The matrix $A$ is in echelon form. There are three pivot columns, so the dimension of $\text{Col } A$ is 3. There are no columns without pivots, so the equation $A\mathbf{x} = \mathbf{0}$ has only the trivial solution $\mathbf{0}$. Thus $\text{Nul } A = \{\mathbf{0}\}$, and the dimension of $\text{Nul } A$ is 0.
