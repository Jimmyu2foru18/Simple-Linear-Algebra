Section 1.1: Systems of Linear Equations

Assigned problems: 9, 11. Source: linearAlgebraSolutionsComplete.pdf.

What is this section about?

What is a system of linear equations? A system of linear equations is a collection of one or more linear equations involving the same set of variables. The goal is to find values for the variables that satisfy every equation in the system simultaneously.

Concept Overview

A system of linear equations consists of multiple equations that must be satisfied simultaneously. The fundamental question is: can we find values for the variables that satisfy all equations at once?

Each equation can be written in the form:

$$a_1 x_1 + a_2 x_2 + \cdots + a_n x_n = b$$

where $a_1, \dots, a_n$ are coefficients, $x_1, \dots, x_n$ are unknowns, and $b$ is the constant term.

A system of $m$ equations in $n$ unknowns can be compactly represented as the matrix equation:

$$A\mathbf{x} = \mathbf{b}$$

where $A$ is the $m \times n$ coefficient matrix, $\mathbf{x}$ is the $n \times 1$ vector of unknowns, and $\mathbf{b}$ is the $m \times 1$ right-hand side vector.

Two perspectives (Strang):
  • Row picture: Each row represents one equation. We seek a point $\mathbf{x}$ that satisfies all equations simultaneously.
  • Column picture: We take linear combinations of the columns of $A$ to produce $\mathbf{b}$.

Problem 9

Problem: The system has already been reduced to triangular form. Begin by scaling the fourth row by 1/2 and then replacing R3 by R3 + (3)R4. Next, replace R2 by R2 + (3)R3. Finally, replace R1 by R1 + R2. Find the solution set.

Solution

After scaling the fourth row by 1/2 and replacing R3 by R3 + (3)R4, then replacing R2 by R2 + (3)R3 and finally R1 by R1 + R2, the system reduces to:

x1 = 4, x2 = 8, x3 = 5, x4 = 2

The solution set contains one solution: (4, 8, 5, 2).

Problem 11

Problem: First, swap R1 and R2. Then replace R3 by R3 + (–3)R1. Finally, replace R3 by R3 + (2)R2. Find the solution set.

Solution

After swapping R1 and R2, then replacing R3 by R3 + (–3)R1, and finally R3 by R3 + (2)R2, the last row of the augmented matrix requires 0 = 2, which is a contradiction.

The system is inconsistent. The solution set is empty.
