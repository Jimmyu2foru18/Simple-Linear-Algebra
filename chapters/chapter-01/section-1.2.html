What is this section about?

What is row reduction? Row reduction (Gaussian elimination) is a systematic method for solving systems of linear equations by transforming the augmented matrix into echelon or reduced echelon form using elementary row operations.

Core Lecture, Gilbert Strang (MIT)

Concept Overview

Gaussian elimination is a systematic algorithm for solving systems of linear equations. The method transforms the augmented matrix $[A|\mathbf{b}]$ into upper triangular form using elementary row operations, making the system easy to solve by back substitution.

Elementary Row Operations

  • Type I: Swap two rows ($R_i \leftrightarrow R_j$)
  • Type II: Multiply a row by a nonzero scalar ($R_i \leftarrow c \cdot R_i$)
  • Type III: Add a multiple of one row to another ($R_i \leftarrow R_i + c \cdot R_j$)
Mnemonic: "Zero Below, Solve Above"
Create zeros below each pivot (going down columns). Then solve from the bottom up (going up rows).

Problem 5

Problem: Determine whether the given matrix is in reduced echelon form, echelon form, or not echelon form. (Matrix involves all-zero rows.)

Solution

The matrix with all-zero rows is not in echelon form because the zero rows are not at the bottom, or the leading entry conditions are not satisfied. Not echelon form.

Problem 7

Problem: Row reduce the augmented matrix and find the general solution. The matrix has columns that reduce to show pivot columns 1 and 3, with column 2 free.

Solution

After row reduction, the basic variables are x1 and x3. The remaining variable x2 is free.

General solution: x1 = -5 - 2x2, x3 = 3 - x2, where x2 is free.

Problem 9

Problem: Row reduce the augmented matrix and find the general solution. The matrix reduces with pivot columns 1 and 2, with column 3 free.

Solution

After row reduction, the basic variables are x1 and x2. The remaining variable x3 is free.

General solution: x1 = 9, x2 = -4, where x3 is free.

Problem 11

Problem: Row reduce the augmented matrix and find the general solution. The matrix reduces with pivot column 1, with columns 2 and 3 free.

Solution

After row reduction, the basic variable is x1. The remaining variables x2 and x3 are free.

General solution: x1 = -2 - 3x2 - 4x3, where x2 and x3 are free.

Problem 13

Problem: Row reduce the augmented matrix and find the general solution. The matrix reduces with pivot columns 1, 2, and 4, with columns 3 and 5 free.

Solution

After row reduction, the basic variables are x1, x2, and x4. The remaining variables x3 and x5 are free.

General solution: x1 = 15 - 2x3 - 5x5, x2 = -3 + x3 + 4x5, x4 = -9, where x3 and x5 are free.
