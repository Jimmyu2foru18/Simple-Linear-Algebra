Detailed Topic Breakdowns

Linear Independence

A set of vectors {v1, v2, ..., vk} is linearly independent if the only solution to c1*v1 + c2*v2 + ... + ck*vk = 0 is c1 = c2 = ... = ck = 0. If any nonzero coefficients produce zero, the vectors are dependent.

Span and Basis

The span of a set of vectors is all possible linear combinations. A basis for a vector space V is a set of vectors that are both linearly independent and span V. Every vector in V can be written uniquely as a linear combination of basis vectors.

Dimension

The dimension of a vector space is the number of vectors in any basis for that space. All bases for a given space have the same number of vectors. dim($\mathbb{R}^n$) = n. The dimension of a subspace is less than or equal to the dimension of the parent space.

Rank and Matrix Spaces

The rank of a matrix is the dimension of its column space (or row space). The rank equals the number of pivot columns. It measures how ch "information" the matrix preserves.

Mathematical Rigor

Derivation: Independence Test via Matrix

To test if vectors v1, v2, ..., vk in $\mathbb{R}^n$ are independent:

$$Form matrix A = [v1 v2 ... vk] $$Solve Ax = 0$$ $$If only trivial solution x = 0 exists: independent$$ If nontrivial solution exists: dependent$$

The vectors are independent exactly when $\text{rank}(A)$ = k.

Derivation: Uniqueness of Basis Representation

If {v1, ..., vn} is a basis for V and v = c1*v1 + ... + cn*vn = d1*v1 + ... + dn*vn, then:

$$(c1-d1)*v1 + ... + (cn-dn)*vn = 0 $$By independence: c1-d1 = 0, ..., cn-dn = 0 Therefore: ci = di for all i$$$$

Basis representations are unique.

Learning Strategies

Mnemonic Devices

Mnemonic: "INDEPENDENT = No Empty Weight"

A set is independent if no vector in the set can be written as a combination of the others. Like people: if no one's weight comes from standing on others' shoulders, they're independent.

Mnemonic: "Basis = Just Right"

A basis has exactly the right number of vectors: enough to span the space, but not so many that they become dependent. Not too few (can't span), not too many (dependent).

Study Tips

  • Always test independence by solving Ax = 0 where A has the vectors as columns
  • More vectors than dimensions (k > n in $\mathbb{R}^n$) always means dependence
  • The standard basis for $\mathbb{R}^n$ is e1, e2, ..., en
  • To extend a linearly independent set to a basis, add vectors from the standard basis that aren't already in the span
  • Dimension is invariant - all bases have the same size

Worked Examples

Example 1: Testing Independence

Problem: Determine if v1 = [1, 2, 3]^T, v2 = [2, 5, 7]^T, v3 = [3, 7, 10]^T are independent.

Solution:

  1. Form A = [[1, 2, 3], [2, 5, 7], [3, 7, 10]]
  2. RREF: [[1, 0, 1], [0, 1, 1], [0, 0, 0]]
  3. Rank = 2 < 3 (number of vectors)
  4. Nontrivial solution exists: v3 = -v1 - v2
  5. Vectors are dependent.

Example 2: Finding a Basis

Problem: Find a basis for the subspace S = span{[1, 2, 1]^T, [2, 4, 2]^T, [1, 0, 1]^T}.

Solution:

  • Note: v2 = 2*v1, so v2 is dependent on v1
  • Check if v3 is independent of v1: not a ltiple
  • RREF of [v1 v2 v3] gives pivots in columns 1 and 3
  • Basis: {[1, 2, 1]^T, [1, 0, 1]^T}
  • dim(S) = 2

Practice Problems

Problem Set 9

Problem 1: Are the vectors [1, 1, 0]^T, [0, 1, 1]^T, [1, 0, 1]^T in R^3 independent?

Hint: Three vectors in R^3 can be independent if they form a basis.

Solution

RREF of [[1,0,1],[1,1,0],[0,1,1]] = I. Rank = 3. Independent.

Problem 2: What is the dimension of the subspace of R^4 spanned by [1, 0, 0, 1]^T, [0, 1, 0, 1]^T, [1, 1, 0, 0]^T, [0, 0, 1, 1]^T?

Hint: Compute the rank of the matrix with these vectors as columns.

Solution

The four vectors are independent (RREF = I). Dimension = 4. They span all of R^4.

Problem 3: Extend {[1, 1]^T} to a basis for R^2.

Hint: Add any vector not in the span of the first vector.

Solution

Add [0, 1]^T or [1, 0]^T or any vector not equal to c*[1, 1]^T. Basis: {[1, 1]^T, [0, 1]^T}.
