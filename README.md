# Simple Linear Algebra

This project provides a structured, web-based curriculum for learning linear algebra. It organizes core mathematical concepts into an accessible format using standard web technologies.

## Overview

The curriculum is designed to guide learners through linear algebra topics using a combination of textual explanations and curated video resources. All content is delivered via a clean, browser-based interface.

## Project Structure

* `/chapters`: Contains modular HTML files for individual topics.
* `/assets`: Houses project-wide CSS and JavaScript.
* `/resources`: Contains links to supplementary video playlists.

## Usage

1. Clone the repository.
2. Open `index.html` in any modern web browser.
3. Follow the chapter progression to work through the material.
